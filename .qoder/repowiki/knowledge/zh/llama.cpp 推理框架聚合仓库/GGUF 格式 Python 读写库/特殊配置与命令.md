- 安装：`pip install gguf`，GUI 模式需 `pip install gguf[gui]`。
- 开发编辑安装：`cd gguf-py && pip install --editable .`（可能需要升级 pip）。
- 运行测试：`python -m unittest discover ./gguf-py -v`。
- 手动发布：`python -m build` 后 `python -m twine upload dist/*`。
- 已安装的 CLI：`gguf-dump`、`gguf-set-metadata`、`gguf-convert-endian`、`gguf-new-metadata`、`gguf-editor-gui`。
