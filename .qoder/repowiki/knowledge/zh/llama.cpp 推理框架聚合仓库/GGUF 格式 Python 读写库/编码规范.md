- 协议常量（magic、version、value type、quantization type、键名）统一集中在 `constants.py`，其他模块通过显式 import 引用而非硬编码字面量。
- 对外 API 通过 `gguf/__init__.py` 的 `from .xxx import *` 扁平导出，调用方无需感知内部子模块边界。
- CLI 脚本位于 `gguf/scripts/` 下并以 `main()` 函数作为 `project.scripts` 入口，保持脚本与库代码解耦。
- 大对象 I/O 优先使用 `numpy.memmap`（Reader）与 `BufferedWriter` + 临时文件（Writer），避免将整个模型载入内存。
- Writer 的状态机用 `enum.Enum(auto())` 表示（`WriterState`），每个写入阶段对应一个明确状态，禁止非法状态跳转。
- 类型标注广泛使用 PEP 604 风格与 `typing.Literal`/`NamedTuple`/`dataclass`，并通过 `py.typed` 声明包内类型提示可用。
