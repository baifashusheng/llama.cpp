- 每个后端在其入口文件（如 `ggml-cpu.cpp`、`ggml-cuda.cu`、`ggml-metal.cpp` 等）中构造一个 `ggml_backend_reg` 结构体，并将 `.api_version` 设为 `GGML_BACKEND_API_VERSION`，随后调用 `ggml_backend_register(reg)` 完成自注册。
- 后端头文件通过 `GGML_BACKEND_API` 宏包裹导出函数，该宏根据 `GGML_BACKEND_SHARED` / `GGML_BACKEND_BUILD` 在 Windows 上展开为 `__declspec(dllexport/dllimport)`，在非 Windows 上展开为 `__attribute__((visibility("default")))`。
- 后端通过 `ggml_add_backend(<NAME>)` 宏在顶层 CMakeLists 中声明，由该宏把 `GGML_<NAME>` 选项映射为 `add_subdirectory(ggml-<lowercase-name>)` 并在非 DL 模式下向 `ggml` 目标追加 `GGML_USE_<NAME>` 编译定义。
- CUDA/SYCL 等 GPU 后端采用 `<op>.cu` + `<op>.cuh` 成对组织算子实现，并在 `template-instances/` 目录下集中显式实例化模板，避免在每个翻译单元重复实例化。
- CMake 中对所有后端目标统一设置 `VERSION ${GGML_VERSION}` / `SOVERSION ${GGML_VERSION_MAJOR}`，并通过 `ggml_add_backend_library` 函数在 `BUILD_SHARED_LIBS` 开启时为后端目标注入 `GGML_BACKEND_SHARED` 宏。
