- 每个架构的 `cpu-feats.cpp` 定义一个形如 `ggml_backend_cpu_<arch>_score()` 的静态函数，并以 `GGML_BACKEND_DL_SCORE_IMPL(...)` 宏导出，供后端动态加载时调用。
- 评分函数采用“基础分=1 + 每开启一项 SIMD 扩展加 1<<n”的位权计分方式，未满足的必需扩展直接返回 0 使该后端被弃用。
- SIMD 能力检测通过编译期宏（`GGML_AVX`/`GGML_AVX2`/`GGML_AVX512`/`GGML_FMA`/`GGML_SVE`/`GGML_DOTPROD` 等）包裹运行时代码，确保在不支持的架构上完全剔除相关分支。
- `quants.c` 与 `repack.cpp` 中针对同一算法的多档 SIMD 实现（SSE/AVX/AVX2/AVX512/AVXVNNI 或 NEON/SVE）通过 `#if defined(__AVX__)` 等预处理器条件并列放置，由编译器择优链接。
- 量化内核普遍以 `GROUP_MAX_EPS_*` 常量控制不同量化格式的数值容差，并在关键路径前用 `assert(k % QK*_SIZE == 0)` 校验对齐约束。
