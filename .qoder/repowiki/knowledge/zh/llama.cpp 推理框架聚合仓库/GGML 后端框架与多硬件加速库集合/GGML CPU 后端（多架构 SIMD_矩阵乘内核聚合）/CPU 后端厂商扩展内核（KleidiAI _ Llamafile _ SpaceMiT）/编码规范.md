- 每个厂商扩展以独立子目录组织，并通过顶层 CMakeLists.txt 以 `add_subdirectory` 方式集成到 ggml-cpu 构建中。
- 内核能力通过函数指针结构体（如 `kernel_info`、`lhs_packing_info`、`rhs_packing_info`）组合并由 `select_kernels(cpu_features, tensor)` 类工厂函数根据 CPU 特性位返回实例。
- SpaceMiT 侧按硬件代际用命名空间 `ime1` / `ime2` 隔离内核，并以 `std::function<size_t(...)>` 类型的 `gemm_kernel_quantize_def` / `moe_gemm_kernel_quantize_def` 统一量化 GEMM 签名。
- 量化数据布局通过 `nrow_block_q2_k<N>` / `nrow_block_q5_0<N>` / `nrow_block_mxfp4<N>` 等带 `static_assert(sizeof(...) == ...)` 校验的模板结构体描述，确保块大小与对齐正确。
