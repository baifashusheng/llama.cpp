本模块由三个相互独立的子目录组成，各自实现一种厂商或开源优化路径，均通过 C/C++ 接口向 ggml-cpu 上层暴露：
- kleidiai/：封装 Arm KleidiAI 库，定义统一的 `kernel_info` / `lhs_packing_info` / `rhs_packing_info` / `ggml_kleidiai_kernels` 函数指针结构体，按 `cpu_feature`（DOTPROD/I8MM/SVE/SME/FP16）和 `ggml_type`（q4_0/q4_k/q8_0/f32）选择具体内核；CMakeLists.txt 通过 `add_subdirectory("${KLEIDIAI_SRC}")` 将外部 KleidiAI 源码树作为子目标引入。
- llamafile/：仅暴露一个 C ABI `llamafile_sgemm(params, ...)` 入口，内部使用 `__VXE__`/`__VXE2__` 条件编译调用 VectorStone VXE SIMD 指令集。
- spacemit/：围绕 SpaceMiT 芯片的 IME1/IME2 向量乘累加单元与 RISC-V V 扩展，按 `spacemit_kernels::ime1`、`spacemit_kernels::ime2` 命名空间划分不同硬件代际的内核；`repack.*` 负责将 Q2_K/Q3_K/Q5_0/Q5_1/MXFP4 等格式重排到 `nrow_block_*` 模板结构，`spine_mem_pool.h`、`spine_barrier.h`、`spine_tcm.h` 提供线程池、屏障与 TCM 内存分配等运行时基础设施。
依赖方向单向：三者均只被 ggml-cpu 调度层调用，彼此之间无相互引用。
