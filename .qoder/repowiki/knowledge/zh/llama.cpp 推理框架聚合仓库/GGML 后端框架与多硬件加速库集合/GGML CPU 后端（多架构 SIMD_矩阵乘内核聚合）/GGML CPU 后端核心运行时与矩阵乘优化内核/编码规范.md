- 各架构专属的量化/反量化实现放在 `arch/<arch>/quants.c`，并通过 CMake 按 `GGML_SYSTEM_ARCH` 选择性地加入源列表，顶层 `quants.c` 提供通用回退。
- 可选加速路径（AMX、Tiled、KleidiaAI、llamafile、Spacemit、HBM、Repack）统一通过 `GGML_USE_*` 编译宏 + 对应的 `#ifdef` 包裹头文件与函数调用进行条件编译。
- CPU 特性探测代码被拆分为独立的 OBJECT 目标（`*-feats`）并以 `-fno-lto` 编译，再由主后端目标链接，避免跨模块优化污染运行时特征检查。
- Tiled GEMM 采用宏瓦片 + 微核结构：`tiled_tile_src0`/`tiled_tile_src1` 描述 tile 数据布局，`tiled_ws` 作为 per-thread workspace，并通过 `static_assert` 校验对齐与大小约束。
- 对外暴露的加速能力（如 AMX buffer type、Spacemit buffer type、KleidiaAI buffer type）以独立的 `ggml_backend_*_buffer_type()` 工厂函数形式注册，由 `ggml_backend_cpu_get_extra_buffer_types()` 统一收集。
