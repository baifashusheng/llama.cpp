模块以 `ggml-cpu.cpp` 为后端入口，通过 `ggml_backend_i` 接口注册 CPU 设备、缓冲区类型（AMX、RISC-V Spacemit IME、Repack、HBM）并实现图计划与执行；`ops.{h,cpp}` + `unary-ops.{h,cpp}` + `binary-ops.{h,cpp}` 按算子类别分派到具体实现；`quants.c/.h` 提供通用量化/反量化原语，`arch/<arch>/quants.c` 在各架构下覆盖。

内部按功能分层：
- 顶层运行时：`ggml-cpu.{c,cpp}`、`traits.cpp`、`repack.cpp`、`hbm.{cpp,h}`、`simd-gemm.h`、`vec.{h,cpp}`、`simd-mappings.h`。
- 专用加速内核（可选编译）：
  - `amx/`：Intel AMX INT8/BF16 + AVX512VNNI 的 GEMM 与 MMQ 路径，通过 `ggml_backend_amx_buffer_type()` 暴露额外 buffer type。
  - `tiled/`：基于 256×256 宏瓦片 + 16×16 微核的分块 GEMM，`tiled-kernel.h` 定义 `tiled_tile_src0/src1`、`tiled_ws` workspace 布局及 `tiled_run_microtile` / `tiled_repack_src0/src1` 等接口，当前仅 x86 AVX2 有向量化实现，其余走标量回退。
  - `kleidiai/`：ARM KleidiAI 库封装，由 CMake 通过 FetchContent 拉取 v1.31.0 源码并链接。
  - `llamafile/sgemm.{cpp,h}`：llamafile 提供的 sgemm 路径，受 `GGML_USE_LLAMAFILE` 控制。
  - `spacemit/`：RISC-V 64-bit Spacemit IME/RVV 加速，含 IME 环境、内存池、RVV kernels 与 repack。
- 架构探测：`arch/<arch>/cpu-feats.cpp` 作为独立 OBJECT 目标编译（禁用 LTO），避免跨模块优化导致 SIGILL，并在动态加载时做运行时特性检测。

依赖方向：`amx/`、`tiled/`、`kleidiai/`、`llamafile/`、`spacemit/` 均被 `ggml-cpu.cpp` 通过条件编译包含，CMake 根据 `GGML_*` 开关决定是否加入源文件集并设置对应 `GGML_USE_*` 宏。
