本模块是 ggml CPU 后端的构建与装配中心，由 `CMakeLists.txt` 中的 `ggml_add_cpu_backend_variant_impl` 函数驱动：
- 核心运行时（`core_runtime`）提供统一的算子分发、SIMD 向量抽象、量化/反量化与 GEMM 调度；`arch_simd` 为 x86/ARM/PowerPC/RISC-V/s390/LoongArch/WASM 提供对应的 `quants.c`、`repack.cpp` 与 `cpu-feats.cpp` 特性探测目标。
- `vendor_extensions`（KleidiAI、Llamafile sgemm、SpaceMiT IME/RVV）作为可选源文件集，在满足平台条件时通过 `target_sources` 追加到同一目标。
- 所有变体共享 `common.h`、`simd-mappings.h`、`traits.h`、`ggml-cpu-impl.h` 等头文件作为跨子模块契约，使核心运行时能调用各架构/vendor 提供的量化与 GEMM 实现。
- 动态加载场景下，每个架构的 `cpu-feats.cpp` 被编译为独立的 OBJECT 目标（`-fno-lto`），避免 LTO 把指令特征探测代码内联进 score 函数导致旧 CPU SIGILL。
- 构建期通过 `GGML_CPU_ALL_VARIANTS` / `GGML_NATIVE` / `GGML_BACKEND_DL` 等开关组合出多个 `ggml-cpu[-tag]` 变体，每个变体携带各自的 `ARCH_FLAGS` 与 `ARCH_DEFINITIONS`（如 `GGML_USE_DOTPROD`、`GGML_AVX512`、`GGML_USE_RVV`、`GGML_USE_CPU_KLEIDIAI`）。
