- 每个量化格式提供成对的 `dequantize_<type>`（标准布局）与 `dequantize_<type>_reorder`（reorder/SoA 布局）两个静态内联函数，签名统一为 `(const void*, int64_t ib, int iqs, dfloat2&)`。
- K-quants（q2_K/q3_K/q4_K/q5_K/q6_K 及 iq*）的反量化实现被 `#if QK_K == 256` 保护，否则走 `GGML_ABORT("... not supported for QK_K != 256")` 路径。
- tile 处理采用 allocate/load_tiles/vec_dot 三段式函数指针 typedef（`allocate_tiles_sycl_t`、`load_tiles_sycl_t`、`vec_dot_q_mul_mat_sycl_t`），按量化类型实例化后组合成完整 kernel。
- SYCL 线程映射通过 `item_ct1.get_group(2)` 取 block 索引、`get_local_id(2)` 取 lane，并以 `#pragma unroll` 展开固定次数的循环。
- MMVQ 中对 reorder 与 plain 两种权重布局分别提供独立函数族（`*_reorder` 与无后缀），并通过 `block_traits::block_to_q8_1_ratio()` 等 traits 解耦量化类型与数据布局。
- 向量化计算优先使用 `sycl::fma` 与 `dfloat2`/`sycl::half2` 双通道运算，并在 `#ifdef GGML_SYCL_F16` 分支下改用 `.s0()/.s1()` 访问器以适配 half 精度路径。
