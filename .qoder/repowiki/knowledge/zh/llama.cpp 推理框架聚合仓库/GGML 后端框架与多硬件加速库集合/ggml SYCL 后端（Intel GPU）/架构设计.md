本模块是 ggml 的后端插件，通过 `ggml-sycl.cpp` 中的 `ggml_backend_sycl_init()` 等接口向 ggml 核心注册 buffer type、buffer ops、tensor op 调度表；运行时由 `ggml_check_sycl()` 单例初始化，从环境变量读取所有开关（GGML_SYCL_ENABLE_DNN、GGML_SYCL_ENABLE_FUSION、GGML_SYCL_ENABLE_FLASH_ATTN 等），并调用 `dpct::dev_mgr` 枚举设备。

- 基础设施层：`core_infrastructure`（`common.hpp`、`base.hpp`、`type.hpp`、`esimd.hpp`）提供 `queue_ptr`、SYCL_CHECK、warp 规约宏，是所有算子共享的根。
- 硬件/内存层：`memory_and_hardware`（`mem.hpp`、`sycl_hw.hpp`）封装 Level Zero / SYCL USM 分配与 Intel GPU 架构族识别，被上层所有算子复用。
- 算子层：按功能拆分为 `linear_algebra_kernels`、`quantized_matmul_kernels`、`convolution_kernels`、`attention_kernels`、`elementwise_reduction_kernels`、`tensor_manipulation_kernels`、`misc_kernels`，每个目录对应一组 ggml op 的 SYCL kernel + 调度入口。
- 融合与优化：`fusion_runtime` 提供 Lightning Attention 索引核与 AdamW/SGD 优化器步，并在 `ggml-sycl.cpp` 中作为独立 op 注册。
- 外部加速：Flash-Attention 在 `attention_kernels` 内根据运行时能力在 oneDNN/XMX → MKL GEMM → 向量核 → tile 核之间分发；GEMM 在 `linear_algebra_kernels` 中以 DNNL matmul 作为后备路径。
- 构建期：`CMakeLists.txt` 强制 `GGML_SYCL_TARGET=INTEL`，链接 IntelSYCL 或 `-fsycl`，可选链接 Level Zero loader（`GGML_SYCL_SUPPORT_LEVEL_ZERO_API`）、oneDNN（`GGML_SYCL_DNNL`，要求 GPU 版且与目标一致）、MKL BLAS；AOT 编译通过 `-fsycl-targets=spir64_gen -device ${GGML_SYCL_DEVICE_ARCH}` 生成 SPIR-V，并根据架构选择 XMX sub-group size（8 或 16）。
