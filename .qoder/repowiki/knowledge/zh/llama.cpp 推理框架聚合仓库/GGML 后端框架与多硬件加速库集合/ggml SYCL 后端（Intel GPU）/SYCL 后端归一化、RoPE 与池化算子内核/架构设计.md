模块按算子族拆分为三个并列的 .cpp/.hpp 对：
- norm.{hpp,cpp}：暴露 `ggml_sycl_op_norm` / `ggml_sycl_op_rms_norm` / `ggml_sycl_op_rms_norm_fused` / `ggml_sycl_op_rms_norm_scale_fused` / `ggml_sycl_op_rms_norm_fused_add` / `ggml_sycl_op_group_norm` / `ggml_sycl_op_l2_norm` / `ggml_sycl_l2_norm_batch`，内部以 `sycl::nd_item<3>` 为工作项，使用 warp-reduce + sub-group barrier 的两阶段规约计算均值/方差。
- rope.{hpp,cpp}：暴露 `ggml_sycl_rope` / `ggml_sycl_rope_back` / `ggml_sycl_rope_fused`，提供 `rope_norm`、`rope_neox`、`rope_multi` 三种布局变体，并通过模板参数 `<bool forward, bool has_ff, typename T, typename D>` 同时支持前向/反向与 float/half 类型；YARN 扩展通过 `rope_yarn` 内联处理。
- pool.{hpp,cpp}：暴露 `ggml_sycl_op_pool2d` / `ggml_sycl_op_pool1d`，分别对应 NCHW 二维与 NCW 一维滑动窗口，按 `enum ggml_op_pool` 分派 AVG/MAX。
所有文件统一通过 `ggml_backend_sycl_context& ctx` 获取 `dpct::queue_ptr` 流并调用 `parallel_for(sycl::nd_range<3>, ...)` 提交 kernel；公共工具（`calculate_offset`、`warp_reduce_sum`、`ggml_sycl_cast`、`ggml_sycl_memcpy_1`、`SYCL_*_BLOCK_SIZE` 常量）来自 `ggml-sycl/common.hpp` 与 `presets.hpp`，依赖方向单向指向 common/presets，不反向依赖上层 backend。
