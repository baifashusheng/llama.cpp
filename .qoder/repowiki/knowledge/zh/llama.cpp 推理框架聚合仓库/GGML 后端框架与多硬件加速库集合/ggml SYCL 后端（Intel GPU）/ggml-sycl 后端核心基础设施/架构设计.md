本模块是 ggml-sycl 后端的最低层（leaf），被上层所有算子头文件通过 `backend.hpp` 统一聚合引入。
- `base.hpp`：纯 C++ 基础层，仅依赖 `<cstdio>`，定义 `g_ggml_sycl_debug` / `g_ggml_sycl_dev_debug` 全局开关以及 `LIKELY/UNLIKELY/GGML_SYCL_DEBUG/GGML_SYCL_DEV_DEBUG` 宏，声明自身为 STRICTLY zero upstream dependencies 的 leaf。
- `common.hpp`：承载全部运行时基础设施——SYCL queue/device 管理（`ggml_backend_sycl_context`、`queue_ptr`、`get_current_device_id`）、设备能力探测（`sycl_device_info`、`ggml_sycl_info()`）、USM 内存池抽象（`ggml_sycl_pool` + `ggml_sycl_pool_alloc<T>`）、多 GPU 张量额外信息（`ggml_tensor_extra_gpu`）、warp/block 规约原语（`warp_reduce_sum/max/all/any`、`block_reduce_policy`）、快速除法/向量拷贝/MAD 等内联工具；同时通过 `#include "dpct/helper.hpp"` 复用 Intel DPCT 适配层，并通过 `GGML_SYCL_DNNL` 条件编译接入 oneDNN。
- `common.cpp`：实现 `ggml_sycl_host_malloc/free`、`ggml_sycl_malloc_device/free_device`（在 Level Zero 可用时走 `zeMemAllocDevice` 绕过 sycl::malloc_device 的 DMA-buf 问题）、`ggml_sycl_get_env`、`release_extra_gpu` 等跨翻译单元符号。
- `backend.hpp`：作为聚合头，集中 include 所有算子头（`binbcast.hpp`、`conv.hpp`、`mmq.hpp`、`fattn.hpp`、`fusion.hpp` 等），是上层构建入口。
依赖方向严格单向：`backend.hpp → common.hpp → base.hpp`，算子头只依赖 `common.hpp`，不反向依赖。
