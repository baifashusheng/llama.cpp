- 对 Level Zero 相关代码整体用 #ifdef GGML_SYCL_SUPPORT_LEVEL_ZERO_API 包裹，使 L0 依赖可被构建开关禁用。
- 所有外部 API 调用（ZE/SYCL）均置于 try/catch(sycl::exception) 中并记录 GGML_SYCL_DEBUG 日志，失败时返回 false 而非抛出异常。
- 设备信息查询统一通过 sycl::device::get_info<> 模板访问 info 枚举，避免直接操作 native handle。
- GPU 架构分类采用静态 map<syclex::architecture, pair<const char*, sycl_intel_gpu_family>> 表驱动映射，未知架构回退到 unknown/UKNOWN。
