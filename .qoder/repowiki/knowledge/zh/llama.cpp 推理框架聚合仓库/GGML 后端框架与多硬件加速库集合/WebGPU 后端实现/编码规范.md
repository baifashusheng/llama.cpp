- 每个算子在 ggml-webgpu-shader-lib.hpp 中成对定义 _pipeline_key 与 _pipeline_key_hash 结构体，并通过 ggml_webgpu_hash_combine 组合字段计算哈希，用于缓存不同变体的 ComputePipeline。
- 算子变体通过向 defines 向量追加 K_F32/Q4_0/Q8_0/V_F32/DST_F32 等宏名来切换数据类型分支，variant 字符串同步拼接类型后缀以便调试标识。
- WGSL 着色器源文件放在 wgsl-shaders/ 目录下，借助 embed_wgsl.py 递归展开 #include 并按 60KB 切块生成 R"(...)" 字面量，避免 C++ 原始字符串长度限制。
- 运行时通过 webgpu_param_arena 以固定 slot_stride 分配 uniform buffer 槽位，每批编码后 reset() 复用同一缓冲区，减少设备内存分配。
- 条件编译开关（GGML_WEBGPU_DEBUG / GGML_WEBGPU_CPU_PROFILE / GGML_WEBGPU_GPU_PROFILE）通过宏包裹 WEBGPU_LOG_DEBUG、WEBGPU_CPU_PROFILE_*、WEBGPU_GPU_PROFILE_* 宏，关闭时展开为空操作。
