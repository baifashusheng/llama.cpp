模块由三层组成：
- 运行时层（ggml-webgpu.cpp）：实现 ggml-backend 接口，维护 wgpu::Instance/Adapter/Device/Queue、全局能力探测（subgroup / subgroup-matrix / dot-product）、参数槽 arena、命令提交批处理与 CPU/GPU 计时。
- 着色器库层（ggml-webgpu-shader-lib.hpp + pre_wgsl.hpp）：定义每个算子的 pipeline_key / shader_decisions 结构体对，负责根据张量类型、内存对齐、设备能力等选择变体并生成带 #define 的 WGSL 源码；pre_wgsl.hpp 提供 C++ 实现的轻量预处理器（支持 include/#if/#elif/#else/#endif、宏展开、表达式求值），供运行时代码在需要时动态预处理 WGSL。
- 构建期嵌入层（CMakeLists.txt + wgsl-shaders/embed_wgsl.py）：CMake 调用 Python 脚本扫描 wgsl-shaders/*.wgsl 与 *.tmpl，递归展开 #include，按 60KB 切块写入 R"(...)" raw string，生成 ggml-wgsl-shaders.hpp 头文件供编译期链接。
依赖方向：运行时 → 着色器库 → 预处理器 → 嵌入头；Dawn/webgpu_cpp.h 仅在非 EMSCRIPTEN 路径下 find_package(Dawn) 引入，EMSCRIPTEN 路径通过 --use-port=emdawnwebgpu 链接 emdawnwebgpu port。
