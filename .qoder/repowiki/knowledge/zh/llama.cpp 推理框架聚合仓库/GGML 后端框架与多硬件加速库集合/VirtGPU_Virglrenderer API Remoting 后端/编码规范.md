- 所有跨进程 APIR 调用统一走 `remote_call_prepare` → `remote_call` → `remote_call_finish` 三段式模式，并在返回后调用 `log_call_duration` 统计耗时。
- 错误路径统一通过 `GGML_ABORT(GGML_VIRTGPU ...)` 宏输出带前缀的诊断信息，区分 LoadLibrary 阶段与 Forward 阶段的错误码空间（INIT_BASE_INDEX / FORWARD_BASE_INDEX）。
- ggml 后端对象（device/buffer/buffer-type）的上下文指针通过 `DEV_TO_GPU`、`BUFFER_TO_GGML_CONTEXT`、`BUFFER_TO_APIR_CONTEXT` 等宏进行类型安全的下转型。
- 前后端函数签名由 `ggmlremoting_functions.yaml` 驱动代码生成，避免手写同步导致的 ABI 漂移。
