模块分为前后端两层，通过共享内存 + DRM ioctl 的 APIR 协议跨进程通信：
- 前端（ggml-virtgpu 库）：`virtgpu.cpp`/`virtgpu.h` 封装 `virtgpu` 结构体，管理 DRM fd、APIR capset 握手、共享内存页 (`virtgpu-shm.*`)；`ggml-backend*.cpp` 实现 ggml 后端接口注册；`virtgpu-forward-*.cpp` 把 device/buffer/buffer-type/backend 的 ggml 调用编码为 APIR 命令并通过 `remote_call_prepare/remote_call/remote_call_finish` 发送。
- 后端（ggml-virtgpu-backend 库，位于 `backend/`）：`apir_cs_ggml-rpc-back.cpp` 接收 APIR 请求并分发到 `backend-dispatched*` 生成的真实后端实现，由 `backend/shared/api_remoting.h` 定义与 virglrenderer 对齐的 wire protocol（HANDSHAKE / LOADLIBRARY / FORWARD）。
- 代码生成层：`ggmlremoting_functions.yaml` + `regenerate_remoting.py` 生成 `virtgpu-forward.gen.h`、`backend-dispatched.gen.h`、`backend/shared/apir_backend.gen.h`，保证前后端函数签名一致。
- 依赖方向：前端 → APIR wire → 后端；两者共享 `backend/shared/` 下的协议头文件，构建时由 CMake 分别链接 libdrm 和 venus_hw.h（通过 ExternalProject 从 virglrenderer 仓库拉取）。
