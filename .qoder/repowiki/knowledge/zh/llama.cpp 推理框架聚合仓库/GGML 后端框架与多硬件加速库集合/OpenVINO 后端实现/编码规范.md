- 每个 GGML 算子在 openvino/op/<op>.cpp 中实现 `translate_<op>(const NodeContext&)` 函数，并在 op_table.cpp 中以 `GGML_OP_CONVERTER(translate_<op>)` 宏声明注册。
- Buffer 与 buffer_type 通过静态 struct + 全局 vector + std::mutex 懒初始化，按 device 索引缓存 ggml_backend_buffer_type 实例。
- OpenVINO 相关资源通过 ggml_tensor->extra 挂载自定义 extra 对象（ggml_openvino_weight_extra / ggml_openvino_quantized_weight_extra / ggml_openvino_tensor_extra），由 buffer_context::tensor_extras 统一管理生命周期。
- GPU 路径统一通过 clEnqueueMemcpyINTEL / clEnqueueMemFillINTEL 走 OpenCL USM，host 路径则用 memcpy/memset，条件分支围绕 ctx->is_remote 判断。
- 编译模型缓存通过 fingerprint（拓扑+端口+权重身份+配置+OpenVINO 版本）定位 <dir>/<hex>.blob，并以 sidecar .manifest 校验权重元数据后再信任命中。
