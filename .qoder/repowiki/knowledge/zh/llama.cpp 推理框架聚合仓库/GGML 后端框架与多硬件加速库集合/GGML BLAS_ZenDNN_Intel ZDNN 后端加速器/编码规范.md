- 每个后端以 `ggml_backend_<name>_context` 结构体持有运行时状态（如 `n_threads`、`work_data`/`work_size`），并通过 `ggml_backend_<name>_graph_compute` 遍历计算图节点进行分派。
- 算子支持判断与执行逻辑采用 `switch(op)` 双分支模式：`supports_op` 返回布尔，`compute_forward` 再 switch 调用具体实现，不支持的 op 统一返回 false 并记录日志。
- 数据类型映射通过模板函数（如 `ggml_to_zendnn_type<T>()`）在 ggml 类型与后端类型之间转换，并在 `ggml_*_gemm` 分发函数中以 `switch(Atype)` 组合输入/输出类型三元组。
- 工作内存复用：上下文中的 `std::unique_ptr<char[]> work_data` 配合 `work_size` 按需扩容，避免每次算子调用重复分配。
- BLAS vendor 选择通过 CMake 定义的 `GGML_BLAS_USE_*` 宏进行 `#if defined(...)` 条件编译，包含头与线程设置 API 随宏切换。
