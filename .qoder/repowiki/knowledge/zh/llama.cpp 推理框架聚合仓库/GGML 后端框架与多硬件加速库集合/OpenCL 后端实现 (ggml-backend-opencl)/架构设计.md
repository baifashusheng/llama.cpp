模块以 `ggml-opencl.cpp` 为唯一入口，实现 `ggml_backend_t` 接口（通过 `ggml-cl_compute_forward` 等函数），在运行时根据张量类型/量化格式选择对应的 OpenCL 内核。

- 内核组织：`kernels/*.cl` 按算子命名（如 `mul_mv_q4_0_f32.cl`、`flash_attn_f32.cl`、`gemm_moe_q8_1_dp4a.cl`），由 `CMakeLists.txt` 中 `GGML_OPENCL_KERNELS` 列表显式注册；每个 .cl 文件对应一个独立的 OpenCL 源，通过 `clBuildProgram` 编译。
- 程序加载策略分三层：① `cl-program-cache.{h,cpp}` 维护进程内 `cl_program` 缓存 + 磁盘二进制缓存（SHA-256(source||compile_opts||device||driver||platform) 作为键，`.clbin` 持久化）；② 可选嵌入模式（`GGML_OPENCL_EMBED_KERNELS`）通过 Python 脚本 `embed_kernel.py` 把 .cl 转为 C++ 字符串头文件；③ 可选预编译二进制库（`GGML_OPENCL_USE_ADRENO_BIN_KERNELS`）通过 `libdl.h` 动态加载 `adreno-opencl-kernels.dll/.so`。
- 设备适配：内部枚举 `GPU_FAMILY` / `ADRENO_GPU_GEN` / `ADRENO_CL_COMPILER_TYPE` 区分 Adreno、Intel 等平台，配合 `fa_tune.h` 中的 Flash Attention 维度表（dk/dv/bm/bn/nsplit/thr）及 `GGML_OPENCL_FA_TUNE` 环境变量覆盖。
- 构建开关：`GGML_OPENCL_TARGET_VERSION`、`GGML_OPENCL_PROFILING`、`GGML_OPENCL_USE_ADRENO_KERNELS`、`GGML_OPENCL_EMBED_KERNELS`、`GGML_OPENCL_USE_ADRENO_BIN_KERNELS` 等 cmake 选项控制编译路径；`GGML_OPENCL_SOA_Q` 启用 SOA 量化布局。
- 依赖方向：本模块仅向上暴露 `ggml-opencl.h`，向下依赖 OpenCL 驱动和 ggml 核心后端抽象，不反向依赖上层推理逻辑。
