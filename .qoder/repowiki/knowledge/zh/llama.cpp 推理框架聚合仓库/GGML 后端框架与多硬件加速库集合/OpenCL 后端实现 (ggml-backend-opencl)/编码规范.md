- 每个 OpenCL 算子独立为一个 `kernels/<op>.cl` 文件，并在 `CMakeLists.txt` 的 `GGML_OPENCL_KERNELS` 列表中显式声明，新增算子需同时添加 .cl 文件和列表项。
- OpenCL API 调用统一通过 `CL_CHECK(err)` 宏包装，失败时记录日志并触发 `GGML_ASSERT(0)`。
- 量化矩阵乘法按数据类型后缀命名（如 `mul_mv_q4_0_f32`、`mul_mv_q5_k_f32_flat`、`mul_mv_mxfp4_f32`），dispatch 层依据张量量化格式匹配对应内核名。
- Flash Attention 的 tile 尺寸与 split 阈值集中定义在 `fa_tune.h` 的常量表中，并通过 `ggml_cl_init_fa_dims_table()` 初始化，允许 `GGML_OPENCL_FA_TUNE` 环境变量在运行前覆盖。
- OpenCL 程序生命周期遵循 "尝试从缓存加载 → 未命中则编译 → 成功后写回缓存" 三段式流程，由 `cl_program_cache_try_load` / `try_save` 封装。
