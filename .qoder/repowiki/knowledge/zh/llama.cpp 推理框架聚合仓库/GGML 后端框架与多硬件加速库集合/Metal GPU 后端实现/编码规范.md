- 每个 ggml_op 在 `ggml-metal-ops.h` 暴露一个 `ggml_metal_op_<op>` 函数，并在 `ggml-metal-impl.h` 中以 `ggml_metal_kargs_<op>` 结构体描述传给 shader 的参数布局。
- Metal shader 间共享的线程组尺寸、SIMD tile 大小等常量统一以 `N_R0_*` / `N_SG_*` / `SZ_SIMDGROUP` 等宏集中定义在 `ggml-metal-impl.h`，而非散落在各 .metal 文件中。
- Function Constant 索引通过 `FC_*` 宏（如 FC_MUL_MM、FC_FLASH_ATTN_EXT、FC_ROPE）集中分配，避免硬编码数字散落。
- Metal shader 通过 `#include "common.h"` / `dequantize.h` / `quantize.h` / `fa_common.metal` 复用公共代码，CMake 在嵌入模式下自动检测这些 include 并注入相应头。
- pipeline 获取一律走 `ggml_metal_library_get_pipeline_*` 系列函数，根据 ggml_tensor 形状与设备属性动态选择具体变体，而不是直接构造 pipeline。
