构建需 macOS 环境且安装 Xcode Command Line Tools；默认通过 `xcrun -sdk macosx metal` 编译 `kernels/*.metal` 生成 `default.metallib`，SDK 版本 ≥ 26.0 额外编译 `ggml-tensor.metallib`。启用 `GGML_METAL_EMBED_LIBRARY` 则改为用 `sed` 拼接头文件后以 `.incbin` 形式嵌入到目标二进制，跳过外部 metallib。调试开关 `GGML_METAL_SHADER_DEBUG` 会关闭 fast-math 与 inline 以便配合 `MTL_SHADER_VALIDATION=1` 运行测试。
