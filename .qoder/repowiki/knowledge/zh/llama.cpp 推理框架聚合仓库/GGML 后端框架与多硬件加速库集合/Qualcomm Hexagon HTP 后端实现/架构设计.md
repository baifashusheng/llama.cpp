模块分为两层：
- Host 侧（C++）：`ggml-hexagon.cpp` 注册 ggml backend；`htp-drv.{h,cpp}` 封装 `remote.h`/`dspqueue.h`/`rpcmem.h` 等 Hexagon SDK 的 Fastrpc 会话、内存映射与错误码转换，暴露 `htpdrv_init`/`htpdrv_get_domain`/`htpdrv_get_arch` 等 C ABI；`htp-opnode.h` 定义 `htp_opnode`/`htp_opformat`，把 ggml 计算图节点转换为带 fused 路径的 HTP 指令序列。
- DSP 侧（C，编译为 `libggml-htp-v73/v75/v79/v81.so`）：`htp/main.c` 是 Fastrpc 服务端入口，实现 `htp_iface_open/start/stop/close/mmap/munmap/profiler/etm/hwinfo`，按固定偏移布局 `htp_context` + main stack + work_queue + per-thread dma_queue + hmx_queue 的统一内存块，并通过 `execute_op()` 分派到 `op_matmul`/`op_binary`/`op_unary`/`op_flash_attn_ext`/`op_ssm_conv` 等处理器。
- 算子实现按类别拆分：`binary-ops.c`、`unary-ops.c`、`matmul-ops.c`、`flash-attn-ops.c`、`ssm-conv.c`、`gated-delta-net-ops.c`、`softmax-ops.c`、`argsort-ops.c`、`get-rows-ops.c`、`allreduce-ops.c` 等，每个文件对应一组 `htp_op_code`。
- 底层 SIMD 原语位于 `hvx-*.{h,c}`（HVX 向量算术、量化、归一化、Flash Attention、MM tiled kernels）和 `hmx-*.{h,c}`（HMX 2D tiled MM、pipeline FA），由 `__HVX_ARCH__`/`__HEXAGON_ARCH__` 条件编译选择 v73/v75/v79/v81 路径。
- IPC 契约由 `htp/htp_iface.idl` 经 `build_idl` 生成 `htp_iface_stub.c`，Host 与 DSP 共享 `htp-ops.h` 中的 `htp_op_desc`/`htp_tensor`/`htp_buf_desc`/`htp_opbatch_req/rsp` 描述符。
- 构建系统：顶层 `CMakeLists.txt` 用 `ExternalProject_Add` 对 v73/v75/v79/v81 分别调用 `htp/cmake-toolchain.cmake`（设置 QURT toolchain、`-mhvx -mhmx`、QCC 链接器脚本）独立编译 skel，最终安装为 `libggml-htp-{v73,v75,v79,v81}.so`；Windows 下额外通过 `INF2CAT`+`SIGNTOOL` 签名驱动包。
