- DSP 端算子统一通过 `htp-ops.h` 中定义的 `htp_op_code` 枚举在 `execute_op()` 的 switch 中分发到 `op_xxx` 函数。
- SIMD 内核按架构版本用 `#if __HVX_ARCH__ >= 75 / 79` 等宏分支组织，同一功能同时提供 HVX 标量/向量化与 HMX tiled 两种实现。
- Host-DSP 共享的数据结构（`htp_op_desc`、`htp_tensor`、`htp_buf_desc`、`htp_opbatch_req/rsp`）集中在 `htp-ops.h`，并在注释中声明与 ggml 类型保持同步。
- Fastrpc 接口函数返回 AEE_* 错误码，并在失败时通过 `FARF(ERROR, ...)` 输出诊断信息。
- 每类算子拆分为 `<op>-ops.c` + `<op>-ops.h` 成对文件，头文件中仅暴露 kernel params 结构与函数原型。
- 构建产物按 Hexagon 架构版本（v73/v75/v79/v81）分别生成独立的 `libggml-htp-<ver>.so`，运行时由 host 端根据 `htpdrv_get_arch` 动态加载。
