本模块由三个并列的 C/C++ 头文件组成，每个文件对应一个 GPU 厂商后端：
- `cuda.h`：直接包含 `<cuda_runtime.h>`、`<cublas_v2.h>`、`<cuda_fp16/bf16/fp8/fp4.h>`，并通过 `CUDART_VERSION` 宏做版本兼容（如 <11020 时重定义 `CU_DEVICE_ATTRIBUTE_VIRTUAL_MEMORY_MANAGEMENT_SUPPORTED` 等）。
- `hip.h`：通过大量 `#define cudaXxx hipXxx` / `#define cublasXxx hipblasXxx` 将 HIP/rocBLAS API 映射到统一的 `cuda*` / `cublas*` 命名空间，并额外定义 GCN/RDNA/CDNA 架构宏（`GCN5`、`RDNA3`、`CDNA2` 等）以及 `nv_bfloat16` 别名；使用 `HIP_VERSION >= 60500000` 分支处理新旧 HIPBLAS 类型差异。
- `musa.h`：以同样方式将 Moore Threads MUSA API（`musa_*`、`mublas_*`）映射到 `cuda*` / `cublas*` 命名空间，覆盖设备内存、流、事件、图执行等全部子集。
三者共同向上层暴露一致的 `cuda*` / `cublas*` 接口，使 ggml-cuda 核心代码无需感知具体厂商。可选依赖 `GGML_USE_NCCL` 在 CUDA 下引入 `<nccl.h>`，在 HIP 下引入 `<rccl/rccl.h>`。
