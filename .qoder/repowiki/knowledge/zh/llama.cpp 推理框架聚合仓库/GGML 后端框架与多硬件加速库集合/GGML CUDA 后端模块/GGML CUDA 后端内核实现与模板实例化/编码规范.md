- 每个算子以 .cu/.cuh 成对组织，.cu 暴露对外函数并由 acc.cu 注册，.cuh 声明内部 kernel 与配置结构。
- FlashAttention 与 MMQ 的模板特化通过 generate_cu_files.py 生成大量 *_instance_*.cu 文件，并在其中调用 DECL_*_CASE(...) 宏展开具体参数组合。
- GPU 架构差异通过 mmq-config-{arch}.cuh 或 vendors/{cuda.h,hip.h,musa.h} 的条件编译分支处理，而非运行时 if-else。
- FlashAttention tile 内核的参数（nthreads/occupancy/nbatch_fa/nbatch_K）以 GGML_CUDA_FATTN_TILE_CONFIG_CASE 宏序列集中声明，并打包为 uint32_t 配置字供运行时查表。
- 共享内存 tile 布局使用 static_assert 在编译期校验 stride/padding 对齐（如 %8==4），确保 bank conflict 规避。
- 量化类型枚举（GGML_TYPE_Q*_*/IQ*/MXFP4/NVFP4）在 switch 中统一映射到 sram_layout 或 block 结构，新增类型需同时更新枚举、layout 与 size 断言。
