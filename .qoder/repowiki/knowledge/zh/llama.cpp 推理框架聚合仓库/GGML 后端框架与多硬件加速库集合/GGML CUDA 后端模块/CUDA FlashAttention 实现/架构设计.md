模块以 fattn.cuh 暴露三个对外接口（ggml_cuda_flash_attn_ext / supported / get_alloc_size），由 fattn.cu 作为入口：根据设备能力与张量形状在 mma-f16、tile、vec 三条路径之间分派，并可选走 sparse 路径。
- fattn-common.cuh 是核心头文件，定义 fattn_kernel_t 函数指针、vec_dot_KQ_t 以及 K/Q 点积与 V 反量化模板族（f16/bf16/q4_0/q4_1/q5_0/q5_1/q8_0），并通过 get_vec_dot_KQ / get_dequantize_V 按 ggml_type 静态分发；还提供 flash_attn_mask_to_KV_max、flash_attn_stream_k_fixup_uniform/general、flash_attn_combine_results 等通用辅助 kernel 与 launch_fattn 调度器。
- fattn-mma-f16.cuh 提供基于 Tensor Core MMA 的 FP16 路径，支持 dense 与 NVIDIA-only 的 sparse 变体（通过 mask_to_sparse_indices + gather）。
- fattn-tile.cuh/.cu 提供 Tile 化路径，使用 GGML_CUDA_FATTN_TILE_CONFIG_CASE 宏为 DKQ×DV×ncols 组合预置 nthreads/occupancy/nbatch_fa/nbatch_K 配置表，并按 NVIDIA/AMD 分别给出 fp16/fp32 两套表。
- fattn-vec.cuh 提供向量级路径，用于小 head 或低占用场景。
依赖方向：fattn.cu → {fattn-mma-f16, fattn-tile, fattn-vec} → fattn-common；common 仅依赖 common.cuh/convert.cuh/vecdotq.cuh，不反向依赖具体路径。
