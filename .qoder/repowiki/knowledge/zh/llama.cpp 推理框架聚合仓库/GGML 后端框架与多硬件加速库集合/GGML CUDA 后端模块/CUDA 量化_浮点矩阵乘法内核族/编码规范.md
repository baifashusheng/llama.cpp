- 每个算子以 .cuh 头文件声明对外 C API（如 `ggml_cuda_mul_mat_q`、`ggml_cuda_mul_mat_f`、`ggml_cuda_mul_mat_vec_q/f`、`ggml_cuda_launch_mm_ids_helper`），.cu 文件内定义模板化 __global__ kernel 与 host 侧 dispatch。
- 通过 `ggml_cuda_mmq_get_config` + `USE_MMA_DATA_LAYOUT` 在编译期/运行期双通道选择 dp4a 或 MMA 数据布局，新增 GPU 架构只需添加对应 `mmq-config-*.cuh`。
- MMQ 将 load_tiles / vec_dot / write_back 封装为 `ggml_cuda_mmq_util_funcs` 函数指针结构体，按 ggml_type 分派到具体实现，避免大量 if/else 分支。
- 共享内存 tile 尺寸通过 `static_assert` 校验 stride % 8 == 4 对齐，确保 warp 访存无 bank conflict。
- MMF/MMVF 使用宏 `DECL_MMF_CASE_EXTERN` / `DECL_MMF_CASE` 批量展开 rows_per_block × cols_per_block × T 的模板实例化，减少重复代码。
- MoE expert 路由通过独立的 ids/expert_bounds 数组与 `mul_mat_f_ids` / `mul_mat_q` 中的 fallback 分支分别处理，保持普通 matmul 路径不变。
