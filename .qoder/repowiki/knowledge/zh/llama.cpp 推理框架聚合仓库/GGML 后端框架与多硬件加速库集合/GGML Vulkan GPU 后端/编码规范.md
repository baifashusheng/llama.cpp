- 每个 GGML 算子在 C++ 侧提供形如 `void ggml_vk_<op>(ctx, subctx, ...)` 的分派函数，并在 `ggml-vulkan-common.h` 中集中声明，供图构建阶段统一调度。
- GLSL 着色器按算子拆分为独立的 `*.comp` 文件，公共类型与函数抽取到 `*.glsl` 头文件（如 types.glsl、utils.glsl、fa_types.glsl、mul_mat_vec_iface.glsl）供多个着色器 include。
- GPU 能力差异通过 CMake 在配置期探测 glslc 是否支持某扩展，并将结果转为 `GGML_VULKAN_*_GLSLC_SUPPORT` 宏，着色器内用 `#ifdef` 条件编译不同实现分支。
- C++ 侧对 AMD/NVIDIA/Intel/Qualcomm 等厂商分别枚举扩展与属性，返回 `vk_device_architecture` 枚举值，用于后续选择 subgroup size、cooperative matrix 策略等优化路径。
- 缓冲区与命令提交通过统一的 `vk_context` / `vk_subbuffer` 抽象封装，算子实现一律接收 `vk_context& subctx` 而非直接操作底层 queue/command buffer。
