- 每个 C/C++ 示例目录自包含一个 CMakeLists.txt，定义 TARGET、add_executable、target_link_libraries PRIVATE llama 并显式声明 cxx_std_17。
- C++ 示例统一通过 include "llama.h" 调用 C API，并在 main 中遵循 llama_backend_init → llama_model_load_from_file → llama_init_from_model → llama_sampler_chain_init → 解码循环 → 释放资源的固定生命周期顺序。
- 命令行参数解析采用 argv 逐项 strcmp 匹配短选项（-m、-n、-ngl 等），缺失值时调用 print_usage 并返回非零退出码。
- 错误路径统一通过 fprintf(stderr, "%s: error: ...", __func__) 输出函数名前缀的错误信息后 return 1。
- Swift 示例将状态封装在 @MainActor ObservableObject 子类（如 LlamaState）中，通过 @Published 属性驱动 SwiftUI UI 更新。
- Android 示例使用 lifecycleScope + Dispatchers.IO/Default/Main 切换协程上下文，在 IO 线程加载模型并在 Main 线程刷新 UI。
