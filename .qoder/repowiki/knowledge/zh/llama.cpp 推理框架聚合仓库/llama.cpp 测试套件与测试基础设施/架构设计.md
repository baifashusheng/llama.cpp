测试目录按被测子系统划分为扁平的 `test-*.cpp` 文件（如 test-log.cpp、test-chat.cpp、test-quantize-fns.cpp）和若干子目录：
- `llama-context/`：独立的可执行测试，包含 case/test-runner/test-util/test-log 等共享实现，通过 `cases-kv.cpp`、`cases-rs.cpp` 分别覆盖 KV 缓存与 recurrent state 的 save/load/copy/rollback。
- `peg-parser/`：PEGBNF/JSON/Python dict 解析器的辅助 token 器与多组测试用例，被 `test-peg-parser.cpp` 聚合编译。
- `fusion/`：融合算子测试数据（MTL.csv）。
- `snapshots/`：远程模型元数据的 JSON Schema 快照，供 `test-quant-type-selection.cpp` 做离线比对。

构建由 `CMakeLists.txt` 集中管理，定义 `llama_build` / `llama_test` / `llama_test_cmd` / `llama_build_and_test` 四个宏，统一处理目标名、链接库（默认 `llama-common`）、C++17、CTest 注册、标签（LABEL main/model/python）和工作目录；大量测试通过条件编译开关（`LLAMA_LLGUIDANCE`、`GGML_METAL`、`APPLE`、`WIN32`、`GGML_BACKEND_DL`、`LLAMA_SANITIZE_ADDRESS`、`NOT WIN32 OR NOT BUILD_SHARED_LIBS`）选择性启用。

运行时框架：每个 `test-*.cpp` 在 `main()` 中构造 `testing` 对象并调用其 `test()` / `bench()` / `assert_*()` API；`testing.h` 是轻量自研断言框架，支持命名/匿名测试、正则过滤、跳过、异常捕获、计时基准与汇总输出。部分测试（如 tokenizer 系列）复用单一可执行并通过命令行参数切换不同 vocab 数据集。
