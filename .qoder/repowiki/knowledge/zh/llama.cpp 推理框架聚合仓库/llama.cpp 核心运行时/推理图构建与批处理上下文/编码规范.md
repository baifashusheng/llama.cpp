- 图输入通过继承 `llm_graph_input_i` 并实现 `set_input(const llama_ubatch*)` 来绑定张量，需要复用时再覆写 `can_reuse(const llm_graph_params&)` 返回 true。
- 所有 KV 缓存变体（dsa/iswa/msa/dsv4/raw/hybrid/recurrent）都以独立的 `*_context` 类 + 对应 `llm_graph_input_*` 组合的方式接入，避免在注意力代码中分支判断后端类型。
- `llm_graph_params::allow_reuse()` 集中比较 ubatch 形状、samplers、cparams.embeddings/nextn_masked/arch/gtype/cvec/loras/cross 等字段来决定图是否可复用。
- 调试开关统一通过环境变量读取（如 `LLAMA_GRAPH_INPUT_DEBUG`、`LLAMA_GRAPH_RESULT_DEBUG`、`LLAMA_BATCH_DEBUG`、`LLAMA_GRAPH_REUSE_DISABLE`），默认关闭。
- 对外 C API 暴露于 `llama-ext.h`，内部新 API 仅允许在此头内出现，注释明确标注为 WIP staging header。
