- 量化决策采用「分类 → 规则」的两段式：先用 `tensor_get_category` 把张量名归入 `tensor_category` 枚举，再由 `llama_tensor_get_type_impl` 按类别和 ftype 分支选择目标 ggml_type。
- 对每个张量先进行 `tensor_allows_quantization` 白名单过滤（仅 weight 结尾、排除 norm/expert gating/position embedding 等），再进入类型选择逻辑。
- 多线程并行通过 `std::vector<std::thread>` + `std::mutex` 计数器模式实现：工作线程从共享 counter 取 chunk，完成后 join 并清空向量复用。
- 大张量按 slab/chunk 切块处理（`max_buf_size` 限制内存峰值），并在每次写入后调用 `ggml_validate_row_data` 校验量化数据合法性。
- 对外 API 以 `llama_*` 前缀暴露，参数统一通过带默认值的 struct（如 `llama_model_quantize_params`）传入，并由 `*_default_params()` 初始化。
