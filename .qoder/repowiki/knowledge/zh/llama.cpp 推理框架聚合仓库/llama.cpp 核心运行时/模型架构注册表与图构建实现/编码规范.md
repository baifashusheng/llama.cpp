- 每个模型类都实现 `load_arch_hparams`、`load_arch_tensors`、`build_arch_graph` 三个虚函数，分别负责解析超参、创建张量、构建 ggml 图。
- 模型类的图构建逻辑放在内部嵌套的 `struct graph : public llm_graph_context` 中，并通过 `build_arch_graph` 返回 `std::make_unique<graph>(...)`。
- 同族模型的图构建代码通过继承公共基类（如 `llm_build_mamba_base`、`llm_build_delta_net_base`、`llm_build_rwkv6_base`、`llm_build_rwkv7_base`）复用，派生类只覆写差异化的 layer 构建方法。
- 对同一架构的不同变体使用模板参数（如 `template<bool embed>`、`template<bool iswa>`）在编译期选择分支，避免运行期 if 判断。
- 权重张量命名统一通过 `tn(LLM_TENSOR_*, "weight", i)` 宏生成，可选偏置张量使用 `TENSOR_NOT_REQUIRED` 标记。
- 家族式派生链中，子类通过 `using graph = 父类::graph;` 或 `using graph = 父类::graph<...>;` 直接复用父类图实现，仅重写必要的重载。
