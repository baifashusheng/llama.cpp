- KV 缓存及其变体统一继承 `llama_memory_i`，并提供对应的 `llama_memory_context_i` 子类来封装 ubatch 迭代与 apply 语义。
- 每个注意力变体（DSA/MSA/iSWA/DSA-iSWA 等）以独立的 `.cpp` 文件实现，仅暴露同名 context 类供上层构造，cells 与 slot 分配逻辑由基类复用。
- 对序列位置的操作（pos_add/pos_div）先累积到 per-cell 的 `shift` 数组并置 `has_shift`，再在需要时一次性应用，避免频繁更新 `seq_pos` 索引。
- 跨 sequence 的 cell 可见性通过 `std::bitset<LLAMA_MAX_SEQ>` 的 seq[i] 字段 + 每个 sequence 的 `seq_pos[s]` 有序集合共同维护，保证 O(1) 成员检查与 O(log n) 最近位置查询。
- 可变状态（如 iSWA 的滑动窗口、hybrid 的子 memory）通过组合多个 `llama_memory_ptr` 并在 `init_batch/init_update` 中分别委派给子实现，再用 `llama_memory_status_combine` 合并返回状态。
