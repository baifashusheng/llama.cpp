本模块按职责划分为四个子层，依赖方向单向向下：
- 文件与内存抽象层（llama-mmap.*）：封装 `llama_file` / `llama_mmap` / `llama_mlock`，提供带 direct I/O 的字节流、按需 mmap 分片与页预取，被上层仅以句柄形式消费。
- 元数据常量层（llama-arch.* + llama-hparams.* + llama-cparams.*）：集中定义 `llm_arch`、`llm_kv`、`llm_tensor`、`LLM_KV`、`LLM_TN` 等枚举与名称生成器，以及 `llama_hparams`（训练期结构体，trivially copyable）、`llama_cparams`（推理期参数）。该层不依赖加载器，供所有模型实现共享。
- 加载器层（llama-model-loader.*）：核心 `llama_model_loader` 负责解析 GGUF metadata、构建 `weights_map`、根据 `TENSOR_*` 标志位（NOT_REQUIRED/DUPLICATED/SKIP/SKIP_IF_VIRTUAL/ALLOW_RESHAPE/READ_LAZY）创建 `ggml_tensor`，并通过 `init_mappings` + `load_all_data` 将权重从 mmap 或 direct IO 搬运到目标 buffer type；内部通过 `lazy_read` 支持 PLE/engram 等大张量的延迟读取。
- 保存器层（llama-model-saver.*）：`llama_model_saver` 反向遍历 `llama_model`，调用 `add_kv` / `add_tensor` 写出 GGUF，并提供 `save(path)` / `save(FILE*)` 两个出口。
- 模型基类（llama-model.* + llama-impl.*）：`llama_model` 暴露纯虚接口 `load_stats/load_hparams/load_vocab/load_tensors/load_arch_hparams/load_arch_tensors/build_arch_graph`，由具体模型实现；`llama_model_base` 提供通用 helper（如 `create_tensor_gate_up_exps`、`nextn_flags`、`load_hparams_hadamard`），并持有 `llama_layer` 巨型结构体（含 attention/ffn/moe/ssm/rwkv/kimi-k3/dflash 等大量字段）。
依赖方向：loader/saver → model → arch/hparams/cparams → mmap；model 实现反过来通过 `llama_model_loader::create_tensor` 反向构造图节点。
