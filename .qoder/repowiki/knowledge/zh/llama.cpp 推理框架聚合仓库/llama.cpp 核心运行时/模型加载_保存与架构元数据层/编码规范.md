- GGUF 键名统一通过 `LLM_KV(arch)(key)` 在运行时拼接，避免硬编码字符串散落在各模型实现中。
- 张量命名通过 `LLM_TN(arch)(tensor, suffix, bid, xid)` 生成，并以 `LLM_TN_IMPL` 作为可比较/可转 string 的值类型。
- 权重加载流程遵循 `create_tensor(..., flags)` + `require_weight(name)` 的两阶段模式，flags 用位掩码表达 TENSOR_NOT_REQUIRED/TENSOR_SKIP/TENSOR_READ_LAZY 等语义。
- 对大型张量采用 `TENSOR_READ_LAZY` 标记 + `lazy_read` 记录 `llama_mmap::ranges`，实际数据仅在需要时通过 `load_data_range` 访问，避免整张载入。
- 模型实现继承 `llama_model_base` 并覆写 `load_arch_hparams/load_arch_tensors/build_arch_graph`，通用逻辑（如 hadamard、SWA pattern、NextN flag）集中在 base 类的 helper 函数中。
- `llama_hparams` 保持 trivially copyable（末尾有 static_assert），新增字段直接追加到 struct 而非引入复杂对象，以保持零开销访问。
