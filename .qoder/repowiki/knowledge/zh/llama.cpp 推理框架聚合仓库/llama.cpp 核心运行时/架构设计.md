src/ 以 llama-*.h/.cpp 为公共 API 边界，将各子能力分层装配：
- 顶层入口 `llama.cpp` + `llama-impl.h/.cpp` 暴露 C/C++ 接口，内部委托给 `llama-model`（加载）、`llama-context`（调度）、`llama-batch`（ubatch 切分）。
- `models/` 下的 150+ 架构实现通过 `llama_model_loader` 注册的 gguf 键映射被 `llama-model-loader` 动态实例化，并由 `llama-graph` 统一构建 ggml_cgraph；不同注意力/MoE 变体则通过 `llama_kv_cache` / `llama_memory_i` 抽象接入，无需修改上层上下文。
- `llama-sampler`、`llama-vocab`、`llama-grammar`、`unicode` 提供推理前后处理管线，被 `llama-batch` 在生成阶段串联。
- `llama-quant` 独立于推理路径，复用同一套 GGUF 读写逻辑完成训练后量化。
- 所有子模块共享 `llama-cparams` / `llama-hparams` 参数结构作为跨层契约，避免直接依赖具体架构实现。
