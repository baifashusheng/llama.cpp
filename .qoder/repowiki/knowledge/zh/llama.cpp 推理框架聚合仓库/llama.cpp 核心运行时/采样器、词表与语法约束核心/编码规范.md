- 对外 API 对象（如 llama_vocab）采用 pimpl 惯用法：头文件仅声明 `struct impl` 并以 `std::unique_ptr<impl>` 持有，实现细节完全隐藏在 .cpp 中。
- 采样器以链式组合方式组织：上层通过 `llama_sampler_chain` 聚合多个 `llama_sampler*`，并通过 `llama_sampler_backend_*` 钩子与后端解耦。
- 语法元素统一使用枚举 + value 的二元组结构（`llama_grammar_element`），type/value 语义由 `llama_gretype` 枚举驱动，便于序列化与栈操作。
- Unicode 分类信息以紧凑位域结构体（`unicode_cpt_flags`）存储，并通过构造函数/`as_uint()` 在 uint16_t 与位域之间按平台字节序转换。
