- 每个视觉/语音/OCR 模型以独立 .cpp 文件实现，并在 models.h 中以 `struct clip_graph_<model>` 声明，构造函数签名统一为 `(clip_ctx*, const clip_image_f32&)`。
- 模型图构建统一重写 `build()` 返回 `ggml_cgraph*`，并通过 `cb(tensor, name, layer_idx)` 对中间张量命名以便调试可视化。
- 需要批量支持的模型通过重写 `bool support_batch() const override { return true; }` 显式声明，默认不支持。
- 对数值稳定性敏感的 FFN/投影路径通过重写 `build_mm(ggml_tensor*w, ggml_tensor*x)` 强制 F32 累加以避免 F16 溢出（见 gemma4a、minimovl 等）。
- LLaVA-UHD 风格的切片预处理通过继承 `mtmd_image_preprocessor_llava_uhd` 并重写 `get_slice_instructions` / `get_slice_align` / `align_round` 等受保护钩子来定制行为。
- 状态ful 子图（code2wav、pockettts-seanet 等）使用 `state_in`/`state_out` 键值映射配合 `list_*_state_slots` 注册持久化槽位，而非把状态塞进主图对象。
