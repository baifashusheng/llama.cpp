运行前需先构建 llama.cpp 得到 build/bin/llama-mtmd-cli，并准备对应 GGUF 模型与 mmproj 文件；依赖通过 pip install -r tools/mtmd/tests/tests-requirements.txt 安装。默认二进制路径为 build/bin/llama-mtmd-cli，可通过 --llama-bin 覆盖；各模型的 --llama-model/--mmproj、--llama-model-2/--mmproj-2、--llama-model-unlimited/--mmproj-unlimited 参数均需指向仓库根下的 gguf_models/* 路径。
