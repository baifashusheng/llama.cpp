模块按职责分为四层：
- 公共 C API 层：`mtmd.h` 声明 `mtmd_context` / `mtmd_bitmap` / `mtmd_input_chunk` / `mtmd_batch` 等不透明类型及 `mtmd_tokenize`、`mtmd_encode_chunk`、`mtmd_batch_*`、`mtmd_gen_audio_*` 等函数，并通过 `MTMD_API` 宏在共享库构建时导出；同时在 `__cplusplus` 分支内定义 `mtmd::context_ptr`、`bitmap`、`bitmaps`、`input_chunks` 等基于 `std::unique_ptr` 的 RAII 包装。
- 内部头：`mtmd-internal.h` 仅被核心实现与单元测试包含，暴露 `mtmd_internal_part` 与 `mtmd_group_mergeable_bitmaps` 等内部结构。
- Helper 辅助层：`mtmd-helper.h` + `mtmd-helper-common.h` 提供面向上层应用的便利接口——图片/音频文件到 `mtmd_bitmap` 的转换、`mtmd_helper_eval_chunks` 端到端评估、M-RoPE 位置计算、ffmpeg 驱动的视频流读取 (`mtmd_helper_video_*`)、以及音频生成管线 (`mtmd_helper_gen_audio_*`)；`mtmd-helper-common.h` 通过全局 `g_logger` 单例统一日志输出，并封装 `decode_embd_batch` 以适配 `llama_batch_ext`。
- 应用层：`mtmd-cli.cpp` 是交互式 CLI 入口，组合 `mtmd` + `mtmd_helper` 完成加载、分词、编码与聊天循环；`deprecation-warning.cpp` 是一个独立的 stub 可执行体，运行后打印弃用提示并返回非零退出码，用于替代旧二进制名。
依赖方向单向：CLI → helper → core (mtmd.h)，helper 与 core 之间通过 C API 解耦，内部实现细节被限制在 `.cpp` 与 `mtmd-internal.h` 中。
