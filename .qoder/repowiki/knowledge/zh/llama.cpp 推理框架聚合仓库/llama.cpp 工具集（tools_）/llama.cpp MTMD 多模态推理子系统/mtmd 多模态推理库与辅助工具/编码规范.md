- 对外 C API 通过 `MTMD_API` 宏包裹并在 `mtmd.h` 中以 `extern "C"` 块声明，内部实现则放在同名 `.cpp` 文件中。
- C 对象在 C++ 侧一律通过自定义 deleter 的 `std::unique_ptr`（如 `context_ptr`、`bitmap_ptr`、`batch_ptr`）管理生命周期，避免裸指针泄漏。
- 可选功能（如视频、音频生成）以独立的结构体与 init/free 成对 API 暴露，并由 `mtmd_helper_init_opt` 等参数结构体传递可选配置。
- 日志输出统一经由 `mtmd-helper-common.h` 中的 `mtmd_helper_logger` 全局实例与 `LOG_DBG/INFO/WARN/ERR` 宏转发到 `ggml_log_callback`。
- 废弃 API 通过 `DEPRECATED(...)` 宏标注并提供迁移建议，同时保留兼容实现。
