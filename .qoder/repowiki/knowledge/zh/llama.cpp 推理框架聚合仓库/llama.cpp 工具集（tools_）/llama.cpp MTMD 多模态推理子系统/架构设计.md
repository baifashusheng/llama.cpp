本模块以 `mtmd.h` / `mtmd.cpp` 暴露的 C API 为对外边界，内部按职责拆分为四层：
- 核心层（clip_core）：`clip-model.h`、`clip-graph.h`、`clip-impl.h`、`clip.cpp` 实现跨模态共享的权重解析、ggml 图构建与前向计算。
- 后端层（image_backend）：`models/*.cpp` 每个文件对应一种视觉/语音/OCR 模型，复用 clip_graph 接口完成各自预处理与图拼接；`mtmd-image.cpp`、`mtmd-audio.cpp` 提供图像/音频预处理流水线。
- 运行时层（helper_and_runtime）：`mtmd-helper*.cpp`、`mtmd-cli.cpp`、`deprecation-warning.cpp` 封装 C++ 包装器、CLI 参数解析与废弃二进制兼容提示。
- 适配层（legacy_model_converters）：Python 脚本把 LLaVA/MiniCPM-V/GLM-Edge 等旧格式权重手术并导出为 GGUF，供上层统一加载。
跨子模块的契约集中在 `clip-model.h` / `clip-graph.h` 定义的权重结构体与 `clip_graph_*` 函数族，所有 models/*.cpp 均通过该契约接入，CLI 则通过 `mtmd.h` 的 C API 调用任意后端。
