模块按职责拆分为四个文件，依赖方向单向：clip-impl.h → clip-model.h → clip-graph.h → clip.cpp。

- clip-impl.h：内部实现头，集中定义 GGUF 键名宏（KEY_*）、张量命名模板宏（TN_*）、projector_type 枚举及名称映射表、日志宏（LOG_INF/ERR 等）、图像数据结构（clip_image_u8 / clip_image_f32 / clip_image_f32_batch）以及跨平台工具函数；对外仅暴露 MTMD_INTERNAL_HEADER 标记。
- clip-model.h：纯数据层，声明 clip_hparams（超参）、clip_layer（Transformer 块）、clip_model（完整模型权重容器，聚合 ViT/backbone/projector/audio-gen 各分支的 ggml_tensor*），以及 clip_seanet / clip_flow_net / clip_code2wav / qf_block / mobilenetv5_block / yasa2_stage 等子结构体，所有成员均为裸指针，由加载阶段填充。
- clip-graph.h：基于 ggml_cgraph 的计算图抽象，定义 clip_graph 基类与 build_vit_opts，提供 build_vit/build_inp/build_attn/build_ffn/build_norm/build_rope_2d/build_patch_merge_permute 等可被具体模型子类复用的图构建原语。
- clip.cpp：唯一 .cpp 实现，包含运行时上下文 struct clip_ctx（封装 gguf_context_ptr、ggml_backend_t、调度器、内存统计、RNG 等），承担 GGUF 解析、权重分发到 clip_model、按 projector_type 分派的具体图构建与 clip_encode/clip_image_batch_encode 等对外 API。

依赖方向严格为 clip.cpp 同时 include 其余三头文件，其他头之间不反向引用，保证 clip.h 作为稳定 C-API 边界（extern "C" 风格接口如 clip_init/clip_free/clip_encode）。
