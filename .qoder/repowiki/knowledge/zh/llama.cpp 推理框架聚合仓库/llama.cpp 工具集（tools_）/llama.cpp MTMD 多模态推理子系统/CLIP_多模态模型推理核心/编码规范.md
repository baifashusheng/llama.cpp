- GGUF 键名与张量命名采用宏常量集中管理（KEY_* 与 TN_* 宏），新增模型分支时通过追加宏而非硬编码字符串接入。
- projector_type 以 enum + static std::map<projector_type, std::string> PROJECTOR_TYPE_NAMES 双向映射形式注册，新增类型需同时写入枚举与映射表。
- 模型权重全部以裸 ggml_tensor* 字段保存在 clip_model/clip_layer 等结构中，由加载阶段按 TN_* 宏匹配填充，运行期不持有所有权。
- 图像数据通过 clip_image_u8 / clip_image_f32 的 get_ro_buf()/get_pixel() 只读访问，刻意不提供 get_rw_buf() 以避免直接写缓冲的危险模式。
- 日志输出统一走 LOG_TRC/LOG_DBG/LOG_INF/LOG_WRN/LOG_ERR 宏，底层委托给 g_logger_state.log_callback，便于外部替换。
- clip_graph 采用虚基类 + 子类覆盖 build() 的模式，通用算子（build_vit/build_attn/build_ffn）在基类中复用，具体模型通过继承扩展差异化逻辑。
