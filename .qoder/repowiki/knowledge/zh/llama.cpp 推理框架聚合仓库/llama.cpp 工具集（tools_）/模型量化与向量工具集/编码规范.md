- CLI 工具统一采用 `common_params` + `common_params_parse(..., LLAMA_EXAMPLE_<NAME>, print_usage)` 解析参数，并在 `main` 开头调用 `std::setlocale(LC_NUMERIC, "C")` 与 `common_init()`。
- 错误处理以抛出 `std::runtime_error` 为主，外层 `try/catch` 捕获后打印 `err.what()` 并 `exit(EXIT_FAILURE)`。
- GGUF I/O 通过 `gguf_context` + `ggml_context` 成对管理，使用 RAII 风格析构函数释放资源（如 `lora_merge_ctx::~lora_merge_ctx`、`file_input::~file_input`）。
- 张量内存分配遵循 `ggml_init({no_alloc=true})` + `ggml_backend_alloc_ctx_tensors` 模式，避免运行时动态分配。
