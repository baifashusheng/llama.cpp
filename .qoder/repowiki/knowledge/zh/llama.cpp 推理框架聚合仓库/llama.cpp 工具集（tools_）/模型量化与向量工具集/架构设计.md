本模块包含三个相互独立的 C++ 可执行工具，各自拥有独立的 `CMakeLists.txt` 入口和 `README.md`，通过顶层构建系统聚合。
- `tools/quantize/`：最小包装器 `main.cpp` 仅转发到 `llama_quantize()`（定义于外部 `quantize.cpp`），由 `tests.sh` 驱动回归测试。
- `tools/export-lora/`：实现 `lora_merge_ctx`，读取 base GGUF + 多个 adapter GGUF，使用 ggml 后端构建计算图（`ggml_mul_mat` + `ggml_scale` + `ggml_add`）按公式 W' = W + Σ scale·BᵀA 合并张量，输出 F16 GGUF；通过 `file_input` 封装 GGUF 元数据与张量偏移读取。
- `tools/cvector-generator/`：通过 `llama_process` + `cb_eval` 回调收集每层 `l_out` 隐藏表示，对正负提示做差并剔除零行，再在 `pca.hpp` / `mean.hpp` 二选一（PCA 或均值）降维，最终写入 `general.architecture=controlvector` 的 GGUF。
依赖方向单向指向 llama.cpp 核心库（`ggml.h`、`gguf.h`、`llama.h`、`common.h`、`arg.h`），工具之间无相互引用。
