tools/ 本身不实现推理逻辑，而是作为子项目的装配层：每个子目录是一个独立的 CMake 子项目（含自己的 CMakeLists.txt、README.md 和 main.cpp），由 tools/CMakeLists.txt 集中 add_subdirectory 注册。
- 条件编译：LLAMA_BUILD_SERVER 控制 server/ui/cli 三件套；GGML_RPC 控制 rpc-server；GGML_METAL 控制 tuning；NOT GGML_BACKEND_DL AND GGML_CPU 控制 cvector-generator/export-lora（直接链接 CPU backend 符号）；EMSCRIPTEN 下全部跳过。
- 运行时依赖分层：server 提供 HTTP API，ui 通过 SvelteKit 前端消费该 API；mtmd 为 tts、imatrix 等工具提供多模态后端；quantization_tools、data_tools、inference_benchmarks、cli_tools、tuning 各自围绕 ggml/gguf 库做单用途处理。
- 测试与基准：server 与 mtmd 自带 Python/Shell 集成测试，其余工具以 README + tests.sh 形式自测，无统一测试入口。
