本模块由三个相互协作但职责独立的子系统组成，均面向 HTTP /tools 接口向外暴露：
- `server-decision.*`：实现 TypeSafe `/v1/systemone` 决策模型（OPENJEV/LEV/KEV/NIMBLE/PPLX_DECIDER/VLLM_DECISION2/LFM2_D1/CLEF 等），核心是 `server_decision_context`，根据模型元数据解析 question/state、渲染 prompt、填充 `server_task`，并按变体分组复用公共前缀；`server_decision_group_tasks` 将共享前缀的 task 聚合到同一 slot。
- `server-mcp.*`：实现 MCP (Model Context Protocol) 客户端，`server_mcp_transport` 抽象 JSON-RPC 会话，`server_mcp_stdio` 通过 stdio + NDJSON 启动子进程并维护 reader/writer/errlog 三线程；`server_mcp` 管理器持有各 transport 的 shared_ptr 缓存、死服务冷却表与全局 tool registry，对外提供 list_tools/call_tool。
- `server-tools.*`：定义 `server_tool` 抽象基类及多个具体实现（read_file/grep_search/exec_shell_command/write_file/edit_file/get_info 等），统一通过 `server_tools::setup` 注册，并由 `server_http_context::handler_t handle_get/handle_post` 路由；可选的 `server_tools_runtime` 将每个调用隔离到独立子进程执行。
依赖方向：`server-tools` 依赖 `server-mcp`（把 MCP 工具包装成 `server_tool`）和 `server-http`/`server-queue`；`server-decision` 仅依赖 `server-common` 与 `server-task`，不反向依赖另外两个子系统。
