- 新增一种决策模型通过在 `server_decision_context` 中按 `common_decision_type` switch 分支添加行为（can_share_prompt/can_use_images/fill_task_* 等），而非修改公共路径。
- 新增内置工具时继承 `server_tool` 虚基类，实现 `get_definition()` 与 `invoke()`，并在 `server_tools::setup` 的工具注册表中以 name/display_name 形式注册。
