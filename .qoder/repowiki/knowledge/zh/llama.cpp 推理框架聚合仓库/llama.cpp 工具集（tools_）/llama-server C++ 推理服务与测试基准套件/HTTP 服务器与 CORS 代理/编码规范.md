- handler 统一返回 `std::unique_ptr<server_http_res>`，通过 `is_stream()` 区分普通响应与流式响应，流式由 `next()` 回调逐块产出。
- 路由注册走 `get/post/del(path, handler)` 三件套，路径自动拼接 `path_prefix` 后注册到所有监听器。
- 跨域与鉴权逻辑集中在 `set_pre_routing_handler` 中间件中，按 CORS → 就绪状态 → API Key 的顺序短路返回。
- GCP Vertex AI 兼容行为通过环境变量（`AIP_MODE`、`AIP_PREDICT_ROUTE`、`AIP_HTTP_PORT` 等）驱动，并在 `register_gcp_compat()` 中集中挂载。
- 对外部代理透传的自定义头统一使用 `x-llama-server-proxy-header-` 前缀，在代理侧剥离前缀后再转发。
