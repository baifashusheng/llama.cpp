模块按用途拆分为两个独立子目录：
- `bench.py` + `script.js` + `prometheus.yml` 构成端到端压测管线：Python 脚本通过 `subprocess` 拉起 `llama-server`（默认 `../../../build/bin/llama-server`，可通过 `LLAMA_SERVER_BIN_PATH` 覆盖），轮询 `/health` 等待就绪后以环境变量 `SERVER_BENCH_*` 驱动 k6 执行 `script.js`；k6 使用 xk6-sse 扩展发送 OpenAI Chat Completions 请求并导出 `k6-results.json`；随后 Python 从 Prometheus（`http://localhost:9090/api/v1/query_range`）拉取 `prompt_tokens_seconds`、`predicted_tokens_seconds`、`kv_cache_usage_ratio` 等指标，用 matplotlib 生成 `.jpg` 图表与 `.mermaid` 文本，并把汇总结果写入 `results.github.env` 供 GitHub Actions 消费。
- `speed-bench/` 是轻量级客户端，直接连接已有 `llama-server` 的 `/v1/chat/completions`，从 HuggingFace `nvidia/SPEED-Bench` 数据集加载样本，按 category 并发执行并统计 per-turn 的 prompt/predict 吞吐、延迟与 draft acceptance rate，支持 `speed_bench_compare.py` 对 baseline/speculative 两次运行做 diff。
依赖方向单向：Python 编排层 → 外部二进制（llama-server/k6/prometheus）→ OpenAI 兼容 API；模块内部无共享代码，两个子目录各自拥有独立的 `requirements.txt`。
