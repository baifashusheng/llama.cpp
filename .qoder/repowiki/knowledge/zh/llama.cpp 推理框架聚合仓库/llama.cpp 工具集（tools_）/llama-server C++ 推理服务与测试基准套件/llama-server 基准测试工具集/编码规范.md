- 外部可执行文件路径通过环境变量覆盖（`LLAMA_SERVER_BIN_PATH`、`BENCH_K6_BIN_PATH`），未设置时回退到相对路径默认值。
- 命令行参数统一使用 argparse，并在 `main(argv=None)` 入口中解析，便于单元测试注入参数。

- 测试结果以结构化 JSON 落盘（`k6-results.json`、`results.github.env`、`speed_bench.py` 的 `--output`），并通过 `escape_metric_name` 等辅助函数将指标名规范化为 GitHub Actions 可用的键。
