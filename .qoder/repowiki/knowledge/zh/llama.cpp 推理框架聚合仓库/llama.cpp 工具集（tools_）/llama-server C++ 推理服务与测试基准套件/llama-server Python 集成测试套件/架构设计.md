测试套件以 pytest 为核心，按职责分为三层：
- fixtures/：一组独立的 Python MCP 子进程（echo/crash/burst/slow/malformed/grandchild），实现 JSON-RPC 2.0 over stdio，作为被测 server 的外部 MCP 依赖。
- unit/：每个被测能力一个 test_*.py 文件（chat_completion、stream、tools_builtin、mcp_servers、security 等），通过 utils.py 中的 ServerProcess / ServerPreset 启动真实的 ../../../build/bin/llama-server 进程并以 HTTP 方式断言响应。
- conftest.py + tests.sh：会话级 fixture 负责端口分配（多 worker 时递增 PORT）、模型预设加载（FileLock 串行化下载）以及每个测试后自动停止所有已启动的 server 进程；tests.sh 封装 pytest 执行，默认使用 pytest-xdist worksteal 并行 4 worker，并通过 -m "not slow" 跳过标记为 slow 的用例。
依赖方向单向：unit → utils → 外部 llama-server 进程；fixtures 被 mcp_servers 测试间接拉起，不反向依赖测试代码。
