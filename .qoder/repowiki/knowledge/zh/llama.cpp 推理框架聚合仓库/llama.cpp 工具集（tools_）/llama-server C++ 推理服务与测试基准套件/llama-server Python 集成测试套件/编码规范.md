- 测试用例通过 `ServerPreset.<preset>()`（如 router()、basic()）构造 ServerProcess，再链式设置参数并调用 `.start()` 启动真实 llama-server 进程。
- HTTP 请求统一通过 `server.make_request(method, path, data=...)` 发起，断言 `res.status_code == 200` 且 `res.body` 结构符合预期。
- 涉及外部资源（模型下载、MCP 子进程）的用例使用 try/finally 块确保 `server.stop()` 在异常路径下也被调用。
- MCP 相关测试将子进程脚本放在 fixtures/ 目录，并通过 `--mcp-servers-json` 传入 `{"mcpServers": {...}}` 形式的配置字符串。
- 耗时测试用 `@pytest.mark.slow` 标记，由 tests.sh 默认 `-m "not slow"` 排除，仅在显式启用 SLOW_TESTS 时运行。
