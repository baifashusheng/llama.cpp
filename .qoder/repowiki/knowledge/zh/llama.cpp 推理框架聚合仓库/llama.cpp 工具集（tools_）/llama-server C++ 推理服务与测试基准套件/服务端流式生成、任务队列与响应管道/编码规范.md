- 任务类型通过 `server_task_type` 枚举 + `switch(type)` 分派（如 `need_embd()`、`need_logits()`、`need_sampling()`），新增任务需在枚举与所有 switch 分支中同步扩展。
- 结果对象继承自 `server_task_result` 基类，通过重写 `to_json()`、`is_stop()`、`update()` 等多态接口实现不同格式的 JSON 序列化与流式状态累积。
- 队列回调通过 `on_*` 注册函数注入（`on_new_task`、`on_update_slots`、`on_sleeping_state`），而非构造函数参数，便于运行时装配。
- 需要跨请求存活的流式会话以 `conversation_id` 为键，通过 `stream_session_ptr`（shared_ptr）共享，producer 析构时负责 finalize session。
- 对外暴露的 HTTP 路由以 `*_make_*_handler()` 工厂函数形式返回 `server_http_context::handler_t`，由上层 server.cpp 统一挂载。
