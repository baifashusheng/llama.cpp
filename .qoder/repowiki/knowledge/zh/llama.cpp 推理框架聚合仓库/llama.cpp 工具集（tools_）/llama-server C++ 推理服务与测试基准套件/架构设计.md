顶层 main.cpp 仅转发到 server.cpp 中的 llama_server(argc, argv)，由后者完成所有子模块的装配：server-http 暴露 REST API 并注册路由；server-chat 把 OpenAI Responses / Anthropic / OAI 请求转录为统一的 task_params（经 server-schema 校验）；server-stream + server-queue + server-task 提供 SSE 流式响应与可休眠的任务调度；server-decision/server-tools/server-mcp 在推理过程中按需调用内置 tool 或外部 MCP 子进程；server-models 加载模型权重。tests/ 通过 pytest 启动真实 llama-server 进程并以 HTTP API 驱动端到端验证；bench/ 提供 k6 端到端压测与 SPEED-Bench 吞吐/延迟评估，两者均直接对编译产物进行性能回归。
