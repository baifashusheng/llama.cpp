- Schema 字段通过链式调用构造：`new field_xxx("name", ref) -> set_limits(...) -> add_alias(...) -> set_desc(...)`，描述文本统一使用英文字符串字面量。
- 数值字段区分软限制 `set_limits` 与硬限制 `set_hard_limits`（后者设置 `is_hard_limit = true` 以在求值时抛出异常）。
- 需要特殊校验或跨字段赋值的字段通过 `set_handler(field_handler)` 注入自定义 lambda，而非扩展基类。
- 协议转换函数对缺失关键字段直接抛 `std::invalid_argument`，并以注释标注对应 OpenAI/Anthropic 规范章节（如 `#responses_create-input-input_item_list-item-input_message`）。
