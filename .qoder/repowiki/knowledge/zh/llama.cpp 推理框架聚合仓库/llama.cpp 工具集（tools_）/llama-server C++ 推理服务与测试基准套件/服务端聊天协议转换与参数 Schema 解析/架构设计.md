模块由两个相互独立的子单元组成：
- `server-chat.*`：协议适配层，暴露 `server_chat_convert_responses_to_chatcmpl`、`server_chat_convert_anthropic_to_oai`、`convert_transcriptions_to_chatcmpl`、`server_chat_msg_diff_to_json_oaicompat` 四个函数，将外部 API（OpenAI Responses、Anthropic Messages、Transcriptions）请求体转换为内部 `common_chat_templates` 可消费的 Chat Completions 格式，并负责 OAI streaming diff 到 JSON 的序列化。
- `server-schema.*`：参数 Schema DSL 层，定义 `field` 抽象基类及其派生 `field_num<T>`、`field_str`、`field_bool`、`field_json`、`field_nested`，配合 `field_eval_context`（持有 `task_params`、`llama_vocab`、logit_bias 等上下文）和 `field_handler` 回调，通过 `make_llama_cmpl_schema` 构建字段树并由 `eval_llama_cmpl_schema` 对传入 JSON 求值填充 `task_params`。
依赖方向单向向外：两者均依赖 `server-common.h`/`server-task.h`/`json.h`，schema 还额外依赖 `sampling.h`、`speculative.h` 与 `json-schema-to-grammar.h`；chat 转换器不反向依赖 schema，保持协议适配与参数解析解耦。
