本模块由五个相互独立的 CLI 子项目组成，每个子目录是一个可单独编译的二进制目标，统一通过顶层 CMakeLists.txt 注册：
- `fit-params/`：入口 `main.cpp` 仅转发到 `llama_fit_params()`，核心逻辑在 `fit-params.cpp`。
- `gguf-split/`：自包含的 GGUF 分割/合并工具，使用 `gguf_init_from_file` + `ggml_context(no_alloc)` 直接操作 GGUF 元数据与张量数据块，通过 `split_strategy` 结构体封装按 tensor 数量或字节数切分的策略，并调用 `llama_split_path` 生成带编号的分片文件名；支持 `--dry-run` 与可选的 `--delete-splits`。
- `imatrix/`：最复杂的工具，通过 `llama-ext.h` 暴露的 `collect_imatrix` 回调在推理过程中拦截 `GGML_OP_MUL_MAT` / `GGML_OP_MUL_MAT_ID` 算子的输入激活，经 `IMatrixCollector` 聚合为 per-tensor 的 sum/count/activations，再输出为 legacy `.dat` 或新的 GGUF 格式（含 `LLM_KV_IMATRIX_*` KV），并提供层间余弦相似度、Pearson、L2 距离等统计计算。
- `tokenize/`：最小工具，仅加载 vocab-only 模型，使用 `common_tokenize` 将文本转为 token ID 或 piece 字符串，支持 stdin/file/prompt 三种输入源。
- `tts/`：基于 `mtmd` API 的语音合成演示程序，流程为 backbone 模型处理 prompt → 采样语义 token → `mtmd_helper::gen_audio.step_gen` 迭代生成声学特征 → 写出 WAV。
依赖方向单向指向 llama.cpp 核心库（`llama.h`、`gguf.h`、`ggml.h`、`common.h`、`arg.h`、`log.h`、`speculative.h`、`mtmd.h`），各工具之间无互相引用。
