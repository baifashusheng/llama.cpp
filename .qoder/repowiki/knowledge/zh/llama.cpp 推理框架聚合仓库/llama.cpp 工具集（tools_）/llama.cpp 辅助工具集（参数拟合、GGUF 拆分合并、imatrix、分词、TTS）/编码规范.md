- CLI 入口统一采用 `main` → `common_params_parse(argc, argv, params, LLAMA_EXAMPLE_*, print_usage)` 的模式解析参数，未配置时打印 usage 并返回非零退出码。
- 错误路径统一通过 `LOG_ERR` / `fprintf(stderr, ...)` 输出后 `exit(EXIT_FAILURE)` 或 `return 1`，成功路径则正常返回 0。
- GGUF 相关工具使用 `gguf_init_from_file` + `ggml_context { .no_alloc = true }` 的方式只读加载元数据，避免分配权重内存。
- 二进制 I/O 使用 `std::ofstream/std::ifstream` 并以 `std::ios::binary` 打开，写入前预留 metadata 占位空间后再 seekp 回写。
- 平台差异通过 `#if defined(_WIN32)` 分支处理 Windows 控制台 UTF-8 输出与路径常量。
