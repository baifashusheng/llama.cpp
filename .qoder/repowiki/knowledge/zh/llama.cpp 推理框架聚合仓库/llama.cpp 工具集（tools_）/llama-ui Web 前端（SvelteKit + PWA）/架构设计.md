模块是一个完整的 SvelteKit SPA，采用 Routes → Components → Hooks → Stores → Services → Storage/API 的分层架构：
- `src/routes/` 使用 SvelteKit File-based Routing（`(chat)/chat/[id]`、`search`、根布局），路由通过 hash router 运行于静态部署。
- `src/lib/` 按职责拆分为 components（app/ui 两套组件）、hooks（UI 状态桥接）、stores（Svelte 5 runes 驱动的状态机）、services（无状态 I/O 层，封装 HTTP/Dexie/MCP）、types/enums/constants/utils/styles/vendors。
- 构建由 `vite.config.ts` 驱动，集成 TailwindCSS、SvelteKitPWA、SplashScreen、BuildInfo、Nerdamer、RelativizeBase 等自定义插件；`svelte.config.js` 使用 `@sveltejs/adapter-static` 输出到 `LLAMA_UI_OUT_DIR`（默认 `./dist`）。
- 测试分三个 Vitest project：`client`（浏览器端组件测试）、`unit`（Node 环境纯函数）、`ui`（Storybook 视觉测试），E2E 使用 Playwright。
- 与 CMake 集成：`CMakeLists.txt` 通过 `scripts/ui-assets.cmake` 在编译期把 UI 资源打包为内嵌 C++ 源（`ui.cpp`/`ui.h`），并支持从 Hugging Face 预取版本化资产；`sources.cmake` 声明 npm 构建输入以判断增量有效性。
- 开发脚本 `scripts/dev.sh` 同时启动 Storybook (:6006) 和 Vite dev server (:5173)，并把 `/v1`、`/models`、`/props`、`/tools`、`/slots`、`/cors-proxy` 代理到后端 llama-server。
