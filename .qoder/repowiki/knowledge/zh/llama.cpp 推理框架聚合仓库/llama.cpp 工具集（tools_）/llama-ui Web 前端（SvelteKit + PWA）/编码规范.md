- Store 使用 Svelte 5 runes（`$state`/`$derived`/`$effect`）定义私有字段，并通过 getter 暴露只读响应式视图给组件。
- 服务层（`src/lib/services/`）保持无状态，仅提供静态方法封装 HTTP/Dexie/MCP 调用，所有副作用与状态变更集中在 store 中。
- 组件与 store 之间通过 `src/lib/hooks/` 中的 use-* hook 解耦，hook 负责滚动、拖拽、键盘快捷键、选择器等 UI 关注点，store 仅持有业务状态。
- 测试按 Vitest project 划分：浏览器端组件测试放 `tests/client/**/*.svelte.test.ts`，纯函数单元测试放 `tests/unit/*.test.ts`，Storybook 视觉测试放 `tests/stories/**.stories.svelte`。
- Vite 插件统一放在 `scripts/vite-plugin-*.ts`，并在 `vite.config.ts` 中以工厂函数形式注册，避免配置膨胀。
- CMake 侧通过 `add_custom_target(llama-ui-assets)` 在编译期生成 `ui.cpp`/`ui.h`，并使用 `BYPRODUCTS` 与 copy-if-different 语义保证增量构建。
