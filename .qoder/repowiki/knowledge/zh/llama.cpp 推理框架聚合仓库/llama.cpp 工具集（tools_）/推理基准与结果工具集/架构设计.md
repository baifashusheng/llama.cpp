四个独立的可执行工具并列位于 tools/ 下，每个目录自包含 CMakeLists.txt + main.cpp + 业务实现文件：
- llama-bench / batched-bench / perplexity：CMakeLists 将业务逻辑编译为 `*-impl` 静态库（如 `llama-bench-impl`），main.cpp 仅做薄封装转发到同名入口函数；库层链接 `llama-common`、`llama` 与线程库，并暴露给外部复用。
- results：无 impl 库，直接作为单一可执行目标 `llama-results`，通过 GGUF/GGML API 对模型进行前向推理并写入 tokens/logits 张量，或读取已有 GGUF 结果计算 NMSE 做一致性校验。
依赖方向单向指向核心库 `llama`/`llama-common`/`ggml`/`gguf`，工具之间互不引用。
