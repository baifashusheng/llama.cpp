- 每个基准工具采用「main.cpp 薄壳 + *-impl 库」的分层结构，main.cpp 仅声明并调用同名入口函数（如 llama_bench、llama_batched_bench、llama_perplexity）。
- CMakeLists.txt 统一先定义 `*-impl` 静态库目标，再定义同名可执行目标并 PRIVATE 链接该库，便于被其他工程复用。
- 工具入口遵循 common 框架约定：初始化 common_init → common_params_parse → llama_backend_init/llama_numa_init → common_init_from_params → 执行业务逻辑。
