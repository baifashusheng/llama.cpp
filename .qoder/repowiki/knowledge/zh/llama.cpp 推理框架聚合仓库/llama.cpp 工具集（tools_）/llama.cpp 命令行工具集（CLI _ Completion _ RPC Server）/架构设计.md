本模块由三个彼此独立、各自拥有独立 CMakeLists.txt 的可执行程序组成，均通过顶层 tools/ 目录下的 CMake 聚合构建：
- tools/cli/：实现 `llama-cli`。CMake 将核心逻辑拆分为静态库 `llama-cli-impl`（cli.cpp + cli-client.cpp + cli-context.cpp，链接 llama-server-impl 与 llama-common）和仅含 main.cpp 的 `llama-cli` 可执行入口，main.cpp 直接转发到 `llama_cli()`。
- tools/completion/：实现 `llama-completion`。同样采用 `llama-completion-impl` 库 + main.cpp 入口的模式，依赖 llama-common 与 llama 核心 API，实现完整的对话/补全交互循环。
- tools/rpc/：实现 `ggml-rpc-server` 独立可执行，不依赖 libcommon，而是内联复制 common.cpp 中的路径/缓存目录解析函数以避免耦合；通过 ggml_backend_reg_by_name("RPC") 动态查找并调用 `ggml_backend_rpc_start_server` 启动 GGML RPC 服务。
依赖方向单向：三个工具都只向上依赖 ggml/llama/common 等底层库，彼此之间无相互引用。
