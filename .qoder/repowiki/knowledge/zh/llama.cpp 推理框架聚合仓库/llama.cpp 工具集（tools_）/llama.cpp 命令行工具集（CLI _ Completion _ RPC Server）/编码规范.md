- 每个工具采用「实现库 + 最小 main.cpp」的两段式结构：main.cpp 仅声明并调用一个同名的 `llama_xxx(int argc, char** argv)` 入口函数，便于被其他应用复用实现库。
- 跨平台信号处理统一通过 `#if defined (__unix__) || (defined (__APPLE__) && defined (__MACH__))` 分支注册 SIGINT/SIGTERM，Windows 侧则用 SetConsoleCtrlHandler 映射 CTRL_C_EVENT。
- 命令行参数解析采用短选项+长选项并列的手写 switch 模式（如 -H/--host、-t/--threads、-p/--port），并在未知参数或 help 时打印 usage 后 exit(0)。
- 日志输出统一通过 LOG/INFO/WARN/ERR 宏（来自 log.h），而非直接 printf，以支持统一的日志级别控制。
