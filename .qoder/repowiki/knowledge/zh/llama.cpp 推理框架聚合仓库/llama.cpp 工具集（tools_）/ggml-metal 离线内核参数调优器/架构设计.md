模块由一个可执行目标 `ggml-metal-tuning`（CMakeLists.txt）构成，入口 main.cpp 通过 `tuner_def` 表注册可调用的 tuner；当前仅实现 `fa-vec` 一种 tuner。
- 分层：main.cpp 负责 CLI 解析、后端设备枚举与生命周期管理；fa-vec.cpp/h 封装 flash-attn vec `(Q, NE)` 的图构建、候选集遍历与结果聚合；bench.cpp/h 提供底层基准设施——`perf_cell` 预建图 + `time_cell_median` 中位数计时 + `measure_cell` 带热节流冷却的候选序列测量。
- 依赖方向单向：main → fa-vec → bench → ggml-backend / ggml-cpp / ggml-metal（通过 CMake 的 `target_include_directories` 引入）。
- 扩展点：新增 tuner 只需在 `k_tuners[]` 注册一个 `bool (*)(ggml_backend_t, ggml_backend_dev_t, const tuner_opts&)` 函数，并通过 `tuner_opts` 传递过滤与冷却参数。
- 产物约定：stdout 只输出表格行，所有诊断走 stderr；非零退出码仅表示参数或环境错误，不代表性能失败。
