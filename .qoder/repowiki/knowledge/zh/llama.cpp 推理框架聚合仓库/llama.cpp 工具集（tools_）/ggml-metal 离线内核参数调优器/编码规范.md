- CLI 参数采用短选项 `-x <val>` 与长选项 `--long-name <val>` 并列的手动 strcmp 解析，未知参数直接打印 usage 并返回 1。
- 可调 tuner 通过 `tuner_def` 结构体（name + function pointer）集中注册，main 中线性查找匹配，新增 tuner 只需追加一行。
- 性能测量统一通过 `perf_cell` 预建图 + `time_cell_median` 取奇数次运行的中位数，避免调度开销污染。
- 候选序列测量使用 `measure_cell` 配合 `baseline_cand` 锚点与 `cooldown_opts`，按固定间隔重测基线以检测热节流漂移并触发指数回退重试。
- 调试信息一律写入 stderr，stdout 仅保留结构化表格行，便于 shell 重定向分离日志与产出。
