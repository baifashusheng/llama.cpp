本模块由两个并列的资源目录组成，均作为静态数据被上层推理工具（llama-cli、llama-completion、llama-server）消费：
- `models/templates/`：每个 `.jinja` 文件对应一个 HuggingFace 仓库的 chat template（如 `meta-llama-Llama-3.1-8B-Instruct.jinja`、`deepseek-ai-DeepSeek-V3.1.jinja`），通过 `scripts/get_chat_template.py` 从 HF Hub 拉取并生成，文件名按 `<org>-<model>.jinja` 命名约定组织。
- `grammars/`：每个 `.gbnf` 文件定义一种输出格式的形式化语法（arithmetic、c、chess、english、japanese、json、json_arr、list），供 `--grammar-file` 参数加载以约束采样。
两个子目录之间无相互依赖，仅各自附带 README 文档说明来源与用法；模块本身不包含任何可执行代码，纯资源库。
