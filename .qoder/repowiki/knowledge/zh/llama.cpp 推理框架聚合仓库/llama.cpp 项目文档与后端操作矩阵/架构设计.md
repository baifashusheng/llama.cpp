文档以主题目录划分，无代码依赖，仅作为仓库根级 README 的补充：
- 顶层 `docs/*.md` 为通用指南（build、install、docker、multi-gpu、speculative、function-calling、preset、completions、xcframework、release 等）。
- `backend/` 按硬件/库细分（CUDA、SYCL、OpenCL、Vulkan、CANN、ZenDNN、zDNN、AOCL、BLIS、ET、OPENVINO、VirtGPU、snapdragon 等），每个文件对应一个后端的独立构建/开发说明；其中 `backend/VirtGPU/` 和 `backend/snapdragon/` 进一步拆出子目录，后者还包含 CMakeUserPresets.json 供 IDE 使用。
- `multimodal/` 按模型家族（llava、gemma3、minicpmv*、granitevision、glmedge、MobileVLM 等）各占一文件，由 `multimodal.md` 总览并链接到具体模型页。
- `ops/` 存放每个后端的 `.csv` 算子支持表，由 `scripts/create_ops_docs.py` 从 `test-backend-ops support --output csv` 输出再生成 `ops.md` 表格，形成“测试 → CSV → Markdown”的数据流水线。
- `development/` 面向贡献者（HOWTO-add-model、debugging-tests、parsing、token_generation_performance_tips），另含 `llama-star/idea-arch.{key,pdf}` 等 IDE 工程资源。
- `android/` 仅含一张导入 Android Studio 的截图，Android 主文档在顶层 `android.md`。
依赖方向单向：顶层文档通过相对路径引用 `backend/*`、`multimodal/*`、`development/*` 与 `ops/*.csv`，反向无引用。
