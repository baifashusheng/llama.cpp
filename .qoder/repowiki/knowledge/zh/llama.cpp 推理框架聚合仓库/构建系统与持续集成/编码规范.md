- CMake 工具链按「架构-平台-编译器」命名（如 arm64-linux-clang.cmake、x64-windows-llvm.cmake），每个目标一个独立 toolchain 文件。
- 构建选项通过大写 `GG_BUILD_*` 环境变量在 `ci/run.sh` 中集中解析，再拼接到 `CMAKE_EXTRA` 传给 cmake。
- 脚本以 shebang `#!/usr/bin/env bash` 或 `#!/usr/bin/env python3` 开头，并通过 argparse/参数解析处理可选开关，错误路径统一 exit 非零。
- Snapdragon 构建脚本将 CMake preset 名与目标类型绑定（`arm64-{linux|android}-snapdragon-{debug|release}`），由 build.py 自动推导。
- 发布流程通过 `scripts/release.sh` 修改 `CMakeLists.txt` 中的 `LLAMA_VERSION_{MAJOR,MINOR,PATCH}` 并创建 `llama-rc-vX.Y.Z` 分支，实际打 tag 由 GitHub workflow 完成。
