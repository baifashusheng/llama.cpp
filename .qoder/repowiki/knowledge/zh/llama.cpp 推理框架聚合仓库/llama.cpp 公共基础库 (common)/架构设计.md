模块以 CMake 构建两个静态库目标：`llama-common-base`（仅含 `build-info.cpp`，由 `build-info.cpp.in` 通过 `configure_file` 生成）和 `llama-common`（聚合所有公共源）。内部按职责划分为若干子域：
- 聊天与模板：`chat.h/.cpp` 定义 `common_chat_template` / `common_chat_msg` / `common_chat_params_init_fn` 等核心结构，并组合 `jinja::program`、`autoparser::autoparser` 与 `peg_parser`；`parsers/` 下每个 `<model>.cpp` 实现一个 `common_chat_params_init_<model>` 工厂函数，由 `parsers/parsers.h` 统一声明并通过 `parsers/sources.cmake` 显式注册到 `LLAMA_CHAT_PARSERS_SOURCES`。
- Jinja 引擎：`jinja/` 是独立自包含的子实现（lexer/parser/runtime/value/string/caps），通过 `README.md` 描述其输入标记安全机制，被 `chat.h` 以 `using chat_template_caps = jinja::caps` 暴露给上层。
- 自动解析器：`chat-auto-parser-*` + `chat-peg-parser.*` + `chat-diff-analyzer.*` + `json-schema-to-grammar.*` 构成基于 PEG 的差分模板解析管线，用于在缺少专用 handler 时自动生成 prompt。
- 通用工具：`common.h/.cpp`（CPU/时间测量/示例枚举）、`log.h`、`console.h`、`download.h`、`hf-cache.h`、`imatrix-loader.h`、`fit.h`、`sampling.h`、`speculative.h`、`reasoning-budget.h`、`ngram-{cache,map,mod}.h`、`trie.h`、`unicode.h`、`preset.h`、`arg.h`、`subproc.h`、`llguidance.h`、`http.h`、`base64.hpp`。
依赖方向：本模块向上向 `llama` 库（`llama-cpp.h`、`ggml.h`、`llama.h`）以及外部依赖 `vendor::nlohmann`、`vendor::sheredom`、`cpp-httplib`、`Threads` 暴露接口；可选地通过 `LLAMA_LLGUIDANCE` 编译开关集成 Rust 编写的 `llguidance`（通过 `ExternalProject_Add` 从 GitHub 拉取并 cargo build）。
