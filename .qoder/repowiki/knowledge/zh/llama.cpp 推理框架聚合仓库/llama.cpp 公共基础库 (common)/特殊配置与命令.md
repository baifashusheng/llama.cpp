构建时若仓库根存在 `.git/index`，会通过 `configure_file(build-info.cpp.in)` 注入 Git 版本信息；启用 `LLAMA_LLGUIDANCE` 会触发 `ExternalProject_Add(llguidance_ext ... BUILD_COMMAND cargo build --release --package llguidance)` 从 https://github.com/guidance-ai/llguidance 拉取指定 commit 并链接生成的静态库。新增模型专用解析器需在 `common/parsers/sources.cmake` 中显式追加文件名，否则增量构建不会感知新文件。
